## 2. 关键决策与不变量

- **M1 · 不乱加框与光学克制红线**：
  - **视觉体系不变**：禁止修改既有 `Journal.paper`、`Journal.sheet`、`Journal.slate`、`Journal.muted`、`Journal.berry`、`Journal.overdueSky`、`Journal.titleFamily`/`bodyFamily`（`LXGW WenKai Screen`）及其深色对应值，保持 `ui_design_system_guard_test.dart`、`journal_visual_consistency_test.dart`、`v1833`/`v1834` 配色断言零漂移。
  - **不乱加框**：首页顶部 4 个操作按钮（`待办` / `刷新` / `主题` / `更多`）必须保持原有无外框无底块 `IconButton` + 底部 `11px` 标签；更新时间与今日待交摘要行（`home-sync-status` / `home-due-summary`）必须保持无外框通透文字，严禁包进卡片或加边框底块；筛选栏三胶囊（`搜索与筛选` / 排序 / `添加`）保持轻浅 `parchment`/`sage` 样式，不加重描边。
  - **零重模糊与零额外高度**：普通列表卡片与分组卡严禁使用 `BackdropFilter`（仅 `JournalSliverHeader`、`JournalFloatingDetailHeader`、`JournalFloatingNavBar`、`JournalContextMenu` 既有悬浮层保留模糊）；`JournalGroupedCard` 的阴影、顶边高光、钴蓝微染与左侧 `3dp` 竖条均通过外层 `DecoratedBox` 与内部 `CustomPaint`（`painter` + `foregroundPainter`）绘制，**不引入 `IntrinsicHeight`、不增加任何垂直/水平内边距**，确保紧凑密度一屏条数与 `display_preferences_test.dart` 的 `>= 15%` 高度缩减回归不变。
  - **强调范围精确限定**：仅当首页分组满足 `section.pinned || section.badge == '今天'` 时传入 `JournalGroupedCard(emphasized: true)`；**「明天」分组（同样带 `HomeDayHeadingTone.today` 但 `badge == '明天'`）、普通未来日期、无日期与已逾期分组必须保持 `emphasized: false` 干净纸面**。
- **M2 · 零 `pumpAndSettle()` 超时架构与生命周期硬边界**：
  - **严禁常驻 60fps 无限循环动画**：禁止使用 `AnimationController.repeat()` 或短周期常驻 `Timer.periodic` 驱动空闲动画。
  - **空闲离散单次计时器（One-Shot）**：空闲呼吸（±1px）/眨眼/小踱步采用「单次 `Timer`（间隔 `2200ms–3400ms`）→ 切换离散像素帧（若眨眼再挂一次性 `160ms` 睁眼回调）→ 调度下一次单次 `Timer`」机制。由于单次空闲间隔远大于 `pumpAndSettle()` 的 `100ms` 轮询步长且单帧即静止，全仓既有 `pumpAndSettle()` 用例在首个 `100ms` 步长即刻收敛，**零超时**。
  - **同步态定时隔离**：仅在 `busy == true && !reducedMotion && _active` 时启动 `180ms` 步进 `Timer.periodic` 同步驱动像素小跑帧与星芒字符（`· ✢ ✳ ✶ ✻ ✽`）；`busy` 结束、离页或切后台立即 `cancel()`。
  - **点击互动有限弹簧 + 2 秒自动恢复**：轻点伙伴触发有界 `SpringSimulation` 跳跃（`~320ms` 自然收敛归 `0.0`）+ 同帧 `JournalMotion.tap(store.display)` + 一次性 `2000ms` 短语定时恢复（`dispose` / 切换账号 / 进入 `busy` 时立即取消并清空短语）。
  - **零后台耗电与无障碍**：同时监听 `WidgetsBindingObserver.didChangeAppLifecycleState`（非 `resumed` 立即停全部计时器与动画控制器）与 `TickerMode.of(context)`（切去日历/统计/我的或 `push` 详情页时立即停跑）；`MediaQuery.disableAnimationsOf(context) == true` 时完全禁用空闲/同步计时器与弹性跳跃，仅保留静态对应姿态及点击时的 2 秒短语与触感反馈。
  - **状态行与标题兼容不变量**：首页主标题必须保持原始 `Text('课业手记', style: journal.display)`（不改 `Text.rich`、不改 `style`，`scrollOffset == 0` 时全树仅出现 1 处 `'课业手记'`）；空闲无互动短语时 `home-sync-status` 的文案、布局与右对齐几何与改造前完全一致；`HomeSyncPresentation.from(...)` 与 `_syncProgressLabel(store)`（`'正在刷新作业…'`）文案保持不变。
  - **偏好与备份兼容**：`DisplayPreferences` 新增 `bool showPixelBuddy = true`（JSON 键 `'pixelBuddy'`，旧数据缺失按 `j['pixelBuddy'] != false` 默认 `true`）；`AssignmentStore.saveDisplay` 仍仅在 `widgetRange` 变更时刷新小组件快照；`BackupSnapshot`（schema v5–v9）不承载显示偏好，保持零改动与完全兼容。
- **M3 · 物理弹簧克制原则**：
  - **非手势临界阻尼、手势/点按可打断**：状态展开/箭头旋转/弹窗入场默认使用临界阻尼（阻尼比 `≈ 1.0`，不乱晃）；按压回弹/4 档滑块/侧滑/打卡微弹基于 `AnimationController.unbounded` + `SpringSimulation`，中途再次触发必须从当前实时值与实时速度（`_controller.value` / `_controller.velocity`）连续重定向，严禁硬切跳变。
  - **多模态同帧与减弱动态归零**：视觉弹簧与既有 `JournalMotion.tap` / `pin` / `complete` 同帧触发；`JournalMotion.isReducedMotion(context) == true` 时所有新增弹簧与弹窗动画均退化为 `Duration.zero` 直接落终值。
