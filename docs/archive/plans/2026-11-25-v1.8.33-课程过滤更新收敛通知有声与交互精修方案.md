### 本轮目标（可判定）
1. **M1 课程判期与首页 4 档拼音筛选**：解析课程名中的明确日期/学期并防误判入学年级（如「2025级」）；取消独立「未分组」Tab，无时间依据的空白课仅在「全部学期」末尾保留；首页课程筛选统一为 4 档「本学期 · 本学年 · 往期 · 全部学期」（默认「本学期」），按待办数量优先 + 课名/教师拼音友好排序（复用 `lpinyin`）。
2. **M2 官方活动/广告课自动屏蔽与手动屏蔽**：自动识别「官方举办 / 学习通官方 / 超星官方」等非学校推广竞赛课，默认跳过同步（减请求防 `9010`）并从首页、筛选、日历、统计、提醒与小组件隐藏；支持手动屏蔽任意课程；在「课程管理」底部提供可折叠的「已自动过滤的活动课」（及手动屏蔽）一键恢复兜底，且不破坏 `CourseTermPreferences v1` / 备份 `schema 9` 兼容。
3. **M3 弹层固定高度与统计顶部紧凑单行栏**：带 Tab 或搜索的 `JournalPickerSheet` 改固定高度（约屏高 `72%–75%`，适配键盘弹起不溢出）+ Tab 切换列表轻淡入；统计页顶部 4 选项改单行 4 等分紧凑栏「本学期 · 本学年 · 往期 · 全部」，窄屏大字永不换行并与下方时间窗分段条拉开主次层次。
4. **M4 全站钴蓝主按钮与晴空天蓝逾期配色**：全站 `primaryFill` 去炭黑改手记钴蓝 `#3D63DD`（浅色蓝底白字、深色柔蓝适配，核对 `SnackBar`/开关/复选框/删除按钮全链路 WCAG AA 对比度，并清理 `AssignmentDetailScreen` 残留硬编码炭黑）；首页与统计「已逾期」改为晴空天蓝（浅 `#0369A1 / #E0F2FE`、深 `#5CC8FF / #152B3A`）+ 冷灰标题墨色（`#475569 / #A8B7C5`），同步调柔统计图「待完成」拉开层次。

## 3. 元步骤规格 `M1…M8`

### M1 · 课程名判期、首页 4 档筛选重排与拼音友好排序
- **前置依赖**：无。
- **目标文件与核心符号**：
  - `study_assistant-1.1.0/local_app/lib/src/services/course_term_catalog.dart`：`CourseTermSource`（新增 `courseName`）、`CourseTermScope`（`currentAcademicYear` 标签改 `'本学年'`）、`AcademicTerm.tryParseCourseName`、`CourseTermCatalog.build`、`matchesHomeCoursePicker`、`matchesCoursePickerScope`。
  - `study_assistant-1.1.0/local_app/lib/src/services/assignment_query.dart`：抽离/公开拼音自然比较 helper（如 `compareNaturalPinyin(String a, String b)`，复用现有 `lpinyin` `PinyinHelper.getPinyinE` + `_compareNatural`）。

  - `study_assistant-1.1.0/local_app/lib/src/features/assignment_list_screen.dart`：`_openFilters` 内课程筛选 `showJournalPickerSheet`（参考 L2490–2555）。
- **契约与边界条件**：
  1. **课程名判期 `AcademicTerm.tryParseCourseName(String? raw)`**：
     - 先用正则剥离/屏蔽入学年级与版本期次干扰词：`(?<!\d)20\d{2}\s*(?:级|届|版|年制|期)`，保证 `2025级高等数学`、`高等数学（2025级）`、`2024届毕业设计`、`大学物理2025`（无学期/月份的裸 4 位年份）均返回 `null`。
     - 依次支持：① 已有学年跨度（`2025-2026(1)`、`2025-2026学年第二学期`、`2025-2026春`等，`end == start + 1`）；② 单年季节（`2026年秋`、`2026春季`）；③ 明确年月或年月日（`2026年9月`、`2026.03`、`2026-09`、`2026/03/12`、`202609`，排除 `v2026.03` 等版本号前缀；月 `1..12`、日合法性校验后映射到 `AcademicTerm.fromInstant(DateTime.utc(year, month, 15))`）。
     - 若单条课名命中多个互异学期则返回 `null`；年份限定 `2000..2100`。
     - 在 `CourseTermCatalog.build` 中：`baseTerm`（L442）与正式 `term`（L500–516）同步按 `manual > folder > courseName > activity > ungrouped` 判定，来源为 `CourseTermSource.courseName`，说明 `'按课程名识别（${term.label}）'`。
  2. **4 档筛选契约（取消「未分组」Tab）**：
     - `matchesHomeCoursePicker(courseKey, filterId, {bool hasVisibleItems = false})` 固定 4 档：
       - `'currentTerm'`（默认）：有可见项（且非已归档/非已屏蔽）或 `entry.hasCurrentTermEvidence`；
       - `'currentAcademicYear'`：`entry.state == CourseCatalogState.recalled`、或 `entry.term != null && entry.term!.academicYearStart == currentTerm.academicYearStart`、或有可见项且非已归档（**排除无时间依据且无作业的静默 `ungrouped` 空白课**）；
       - `'pastTerms'`：`entry.state == CourseCatalogState.archived || (entry.term != null && entry.term! < currentTerm)`；
       - `'allTerms'`：返回 `true`（M2 叠加 `!entry.isBlocked`）。
     - 同步更新 `matchesCoursePickerScope(courseKey, CourseTermScope.currentAcademicYear)`，使 `entry.term == null` 的静默空白课不再混入「本学年」。
     - `assignment_list_screen.dart` 的 `filterOptions` 改为 4 项：`本学期`（`currentTerm`）、`本学年`（`currentAcademicYear`）、`往期`（`pastTerms`）、`全部学期`（`allTerms`）；`filterNoticeBuilder` 提示文案改为 `'本学期暂未识别出课程，可切换到「本学年」或「全部学期」查看'`。
  3. **拼音友好排序与空白课沉底**：
     - `buildHomeCourseFilterOptions` 基础排序改为：`compareNaturalPinyin(a.name, b.name)` → `compareNaturalPinyin(a.teacherLabel, b.teacherLabel)` → `a.clazzId` → `a.courseId` → `a.courseKey`；
     - `sortHomeCourseOptionsByCount(options, counts)` 排序层级：① `count` 降序（有待办的课程始终排在前面）；② 同为 `0` 项时，`!ungrouped` 排在 `ungrouped` 之前（保证「全部学期」中无时间依据的空白课沉在末尾）；③ 维持拼音基础序。
- **跨文件耦合点与受影响旧单测**：
  - 检查 `CourseTermSource` 全仓引用（确认无未覆盖 `switch`）。
  - `test/academic_term_scope_test.dart`（参考 L895–932）：删除旧 `'ungrouped'` filterId 断言，更新为 4 档（含 `'currentAcademicYear'`）与 `tryParseCourseName` 正常/年级误判反例测试。
  - `test/home_course_labels_1815_test.dart`（参考 L516–554）：将 `picker-filter-ungrouped` 更新为验证无「未分组」Tab、4 档文案、拼音排序与「全部学期」空白课沉底。
- **必须保留的行为反例**：
  - 反例：`2025级高等数学`（无目录、无作业）→ `tryParseCourseName == null`，`isUngrouped == true`，不出现在「本学期 / 本学年 / 往期」，仅出现在「全部学期」末尾且仍保留同步资格。
  - 反例：`高等数学（2025-2026第一学期）` 与 `2026.03 大学英语` → 正确分别判为 `2025-fall` 与 `2025-spring`。
