## 2. 关键决策与不变量

1. **零外部包体增量的像素与合成路线**：Clawd 全套姿态（巡逻/攀爬/坐姿晃腿/打盹 `zZz`/挂底翻跟头/拎起乱蹬/摸头眯眼/傲娇炸毛）均基于 `CustomPainter` 整数物理像素网格（`cell = floor(rawCell * dpr) / dpr`，`Paint.isAntiAlias = false`）实时绘制；8-bit 音效均在 `InteractionSoundPolicy.kt` 内存中生成 `48 kHz` 16-bit PCM 并经临时缓存文件加载进 `SoundPool` 后立即删除，`assets/` 与 `res/raw/` **零新增文件**。
2. **有限动画与 `pumpAndSettle()` 零超时铁律**：全仓严禁任何 `.repeat()` 与空闲 `Timer.periodic`。所有舞台巡逻、攀爬、弹簧落地（`SpringSimulation`）、气泡进出场及主动冒泡全部采用**有限单次 `AnimationController` + 单次可取消 `Timer` 冷却调度**；一旦进入 `dispose()`、`AppLifecycleState != resumed`、`TickerMode == false`、`MediaQuery.disableAnimations == true`、`ClawdVisibilityMode.off` 或账号切换，立即停止全部控制器并取消全部 `Timer`，确保既有与新增 `pumpAndSettle()` 100% 零超时、零后台耗电。
3. **手势隔离与右侧操作区避让红线**：`ClawdTitleStage` 除 Clawd 本体热区（约 `44×44dp`）与气泡本体药丸外，其余区域一律透传命中（`HitTestBehavior.deferToChild` / `IgnorePointer`），绝不抢占首页 `ListView` 上下滑动手势；Clawd 拖拽/巡逻坐标与 `ClawdSpeechBubble` 水平锚点强制钳制在右侧 4 个操作按钮（`待办 / 刷新 / 主题 / 更多`）左侧安全边界内（至少留 `8dp` 间距），绝不遮挡或拦截顶栏操作图标。
4. **音频联动与免打扰红线**：Clawd 全部 8-bit 音效直接读取 `DisplayPreferences.soundEnabled` 与 `hapticsEnabled`（不新增独立音效开关），在原生端继续经 `InteractionSoundPolicy.shouldPlay` 统一拦截媒体音量为 0、静音/振动模式（`ringerMode != RINGER_MODE_NORMAL`）及来电/通话音频模式；同步 `clawdSyncTick` 采用低增益轻音且不附带振动，避免连续刷屏震手。
5. **业务契约零退化**：不动 `FB-005` 双向确认逾期置底排序、不动 `v3` 通知渠道 ID 与 `SQLite v10` 结构、不动加密备份 schema 与桌面小组件快照触发边界（切换 Clawd 显示档位不重写小组件快照）。

## 3. 元步骤规格（M1–M5）

### M1 · 应用级 `ClawdCompanionController` 与三档显示设置

- **三档显示模型（`display_preferences.dart`、`display_settings_screen.dart`）**：
  - 新增 `enum ClawdVisibilityMode { allPrimaryTabs('全部主页面'), homeOnly('仅首页'), off('关闭') }`，在 `DisplayPreferences` 中新增 `final ClawdVisibilityMode clawdVisibility`（默认 `ClawdVisibilityMode.allPrimaryTabs`），保留计算属性 `bool get showPixelBuddy => clawdVisibility != ClawdVisibilityMode.off` 与 `bool get showClawdOnSecondaryTabs => clawdVisibility == ClawdVisibilityMode.allPrimaryTabs`。
  - **严格向后兼容编解码**：`encode()` 将 `'pixelBuddy'` 写为 `'all' | 'homeOnly' | 'off'`（或当 `off` 时兼容读取）；`DisplayPreferences.decode()` 兼容旧版与异常输入：`false` / `'off'` → `off`；`'homeOnly'` → `homeOnly`；`true` / `'all'` / `'yes'` / 缺省 / 未知值 → `allPrimaryTabs`。`copyWith` 同时支持 `ClawdVisibilityMode? clawdVisibility` 与兼容命名参数 `bool? showPixelBuddy`（传 `false` 映射 `off`、传 `true` 映射 `allPrimaryTabs`，显式传 `clawdVisibility` 优先），减少无关旧测试改动面。
  - `DisplaySettingsScreen` 将原 `SwitchListTile`（`display-pixel-buddy-toggle`）升级为 `JournalGroupTile`（`key: ValueKey('display-pixel-buddy-mode')`，副标题说明三档范围）+ `showJournalPickerSheet<ClawdVisibilityMode>`（禁用原生 `DropdownButton*`，遵守 `JournalGroupedCard` 无裸 `SizedBox` 静态守卫）；保存时沿用 `saveDisplaySetting`，不触发 `widgetSnapshotService.saveAssignments`。
- **全局控制器与挂载接缝（新增 `clawd_companion_controller.dart`、改 `app_shell.dart`）**：
  - `ClawdCompanionController extends ChangeNotifier` 单一真源维护：`mood`（`idle / syncing / dueToday / allClear`）、瞬态互动姿态（`wave / doubleStar / tsundere / petting / grabbed / landing / cheer`）、单一 `1200ms` 连击窗口计数 `comboCount`、累计互动记忆（轻点/摸头/拎起次数、最近访问主栏）、当前气泡 `ClawdSpeechMessage? activeBubble`（含 `id / text / isTsundere / createdAt` 与单次自动收起 `Timer`，默认 `2500ms`）、主动冒泡冷却表（按 `greeting / allClear / dueToday` 分桶记录上次触发时间，同桶冷却 `>= 15 min`）、`celebratePulse` 计数，以及同步帧 `ValueNotifier<int> syncTick`（仅在 `isSyncing && showPixelBuddy && appResumed && tickerEnabled && !reducedMotion` 时运行 `180ms` 步进，其余状态立即停表）。
  - **预留 AI 对话扩展接口**：定义不可变脱敏摘要 `ClawdPageContextSnapshot`（当前主栏路由、`dueToday`、`dueIn3Days`、`overdueCount`、`completedToday`、日历选中日待办数、统计完成率、已关注课程数，**严禁含原始课程名/学生姓名/账号**）与可选回调 `ValueChanged<ClawdPageContextSnapshot>? onBubbleTapExtension`（未注入时点击气泡执行 `dismissBubble()`）。
  - **挂载与单测兜底**：在 `_AppShellState` 创建并持有唯一 `ClawdCompanionController`，通过 `ClawdCompanionScope extends InheritedNotifier<ClawdCompanionController>` 向子树暴露；监听 `assignmentStore` 账号身份变化（`accountEpoch` / `accountHash` 改变或登出）时立即调用 `resetForAccountChange()` 清空连击、气泡、记忆与冷却；当 `_AppShellState._handleStoreIdentityChange` 消费到 `consumeReturnCheckConfirmation()` 时同步触发 `controller.triggerCheer()`。四个一级主页通过 `ClawdCompanionScope.maybeOf(context)` 获取控制器，若在独立单测未包裹 `AppShell` 时回退至页面自持本地实例并在 `dispose()` 释放，确保全仓独立页面测试零崩溃。
  - **彻底清理 `AssignmentListScreen` 旧状态**：删除 `_AssignmentListScreenState` 内的 `_buddyWhisper`、`_buddyWhisperTimer`、`_buddyComboResetTimer`、`_buddyComboCount`、`_buddyTapCount`、`_buddyCelebratePulse`、`_syncSpinnerTimer`、`_syncSpinnerTick` 及 `build()` 内的 `_clearBuddyWhisper()` / `_clearBuddyCombo()` / `_reconcileSyncSpinner()` 副作用调用，改由事件驱动与 `didChangeDependencies` / Store 监听同步至 `ClawdCompanionController`。

### M2 · 等高像素体量 + 首页「课业手记」Shimeji 文字舞台

- **视觉体量与双尺寸规格（`journal_pixel_buddy.dart`、`clawd_title_stage.dart`）**：
  - 首页主舞台默认尺寸提升至与 `Journal.display`（`30sp`，行盒约 `37.5dp`）视觉等高：宽屏 `>= 350dp` 取 **`38.0dp`**，窄屏 `< 350dp` 取 **`32.0dp`**，`JournalLayout.isLargeText(context)`（如 `2.0x` 大字）降级为 **`24.0dp`**；悬浮顶栏 `JournalSliverHeader` 迷你版维持 `mini: true`（`20.0dp`），均通过 `floor(rawCell * dpr) / dpr` 对齐物理像素网格，保持浅宣纸（`#D97757`）与深暖炭（`#E5896B`）双主题锐利无糊边。
  - 在 `_JournalPixelBuddyPainter` 扩展离散像素帧姿态参数：除既有呼吸、双眨眼、探看、小碎步、招手、星花/爱心、4 腿同步小跑外，补齐 **`sitDangle`**（坐姿双短腿向下交替轻晃）、**`napZzz`**（趴卧压低躯干+眯眼+右上浮起像素 `zZz`）、**`climbEdge`**（侧身抱字边上下挪步+探头）、**`hangSlipFlip`**（双手抓字底悬垂→下滑→翻滚一周弹回）、**`petSquint`**（摸头眯眼微扁+像素爱心）、**`grabbedFlail`**（被拎起悬空四腿快速交替乱蹬+惊讶圆眼）与 **`tsunderePuff`**（3+ 连击鼓腮微仰/小炸毛符号）。保留 `Row 2` 净空或动态锚定 `effectiveOriginY`，确保粒子绝不压住额头与眼睛像素。
- **`ClawdTitleStage` 物理文字舞台与手势契约（新增 `clawd_title_stage.dart`，接入 `assignment_list_screen.dart`）**：
  - 采用 `Stack(clipBehavior: Clip.none)` 包裹「课业手记」标题行左侧可用区域，使用 `TextPainter`（同步当前 `TextStyle`、`TextScaler` 及 `FittedBox` 缩放比）精确算出「课业手记」四字真实渲染矩形 `glyphRect`（含单字四等分锚点 `课 / 业 / 手 / 记` 的上沿、左右侧边、下沿基线及「记」字右侧站位点），并将舞台最大右边界钳制在右侧 `actionsRow` 左缘减去 `8dp` 安全间距处。
  - **有限自主巡逻调度**：空闲时通过单次 `Timer`（冷却 `2600ms–4500ms`）在站位与 `glyphRect` 之间触发单次有限动作（跳上字顶巡逻、坐字顶晃腿、趴字顶打盹冒 `zZz`、扒「课」左缘或「记」右缘攀爬、挂字底微滑后翻跟头弹回）；每次位移动画均在 `450ms–900ms` 内精确收敛结束。
  - **三合一桌宠手势与滚动零冲突**：仅在 Clawd 当前实时坐标的独立 `Positioned` 热区（`min 44×44dp`）挂载 `GestureDetector`：
    1. **轻点（`onTap`）**：驱动 `controller.registerTap(...)`，1 击单跳招手（`clawdJump`）、2 击星花双跳（`clawdCombo2`）、3+ 击傲娇小炸毛/爱心（`clawdCombo3`）；
    2. **长按摸头（`onLongPressStart` / `onLongPressEnd`）**：进入 `petSquint` 眯眼呼噜冒像素爱心并触发 `clawdPet` 音效，松手平稳恢复；
    3. **拎起拖拽与弹簧落回（`onPanStart` / `onPanUpdate` / `onPanEnd` / `onPanCancel`）**：手指按住 Clawd 拖动即切入 `grabbedFlail` 悬空乱蹬姿态（触发 `clawdGrab` 音效与讨饶气泡），实时跟随手指偏移（钳制在屏幕左/上安全区与右侧 4 按钮安全线内）；松手后按释放点高度与水平位置运行有限 `SpringSimulation`（`stiffness: 420, damping: 24`）弹性落回字顶最近字位或「记」字右侧站位，触底瞬间触发轻微挤压回弹与 `clawdLand` 音效。
  - **降级保护**：当开启系统「移除动画」（`disableAnimations: true`）、处于 `recoveryScope != null`、`isLargeText` 或可用总宽 `< 330dp` 时，自动关闭自主爬字巡逻与拖拽位移，Clawd 稳态停驻于标题旁默认站位（仅保留静态渲染与点击气泡），确保 `320dp@2x` 零溢出。
