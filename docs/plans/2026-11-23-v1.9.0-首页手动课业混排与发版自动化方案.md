### 元步骤 M1：抽离纯逻辑混排与筛选服务 `HomeManualTimeline`

1. **精确位置**
   - 新增：`study_assistant-1.1.0/local_app/lib/src/services/home_manual_timeline.dart`
   - 轻微导出：`study_assistant-1.1.0/local_app/lib/src/services/assignment_query.dart`（公开静态自然排序比较函数 `compareNaturalPinyin(String left, String right)`，复用现有 `_NaturalKey` 与 `_compareKey`，不重复实现拼音自然排序）。
2. **具体改法与逻辑边界**
   - 定义不可变模型 `HomeTimelineItem`：
     - 两种工厂：`HomeTimelineItem.assignment(Assignment assignment)`、`HomeTimelineItem.manual(ManualEntry entry)`。
     - 字段与 getter：`Assignment? assignment`、`ManualEntry? manual`、`bool get isManual`、`String get itemId`（学习通为 `assignment!.id`，手动为 `'manual:${manual!.id}'`）、`String get pinKey`（学习通为 `AssignmentStore.pinKeyOf(assignment!)`，手动为 `'manual:${manual!.id}'`）、`bool get isExam`（学习通为 `assignment!.isExam`，手动为 `manual!.kind == 'exam'`）、`String get title`、`String get displayCourse`（手动项 `course.trim()` 非空用原值，为空在按课程排序时回退 `isExam ? '手动考试' : '个人待办'`）。
   - 定义 `HomeManualTimeline` 纯静态方法：
     - `static AssignmentDeadlineBucket manualBucketAt(ManualEntry entry, DateTime now)`：
       - `entry.done` → `AssignmentDeadlineBucket.completed`
       - `entry.at == null` → `AssignmentDeadlineBucket.confirmedNoDeadline`
       - `entry.at!.isAfter(now)` → `AssignmentDeadlineBucket.notExpiredWithDeadline`
       - 其余（`!entry.at!.isAfter(now)`）→ `AssignmentDeadlineBucket.overdue`（无论 `todo` 或 `exam`，过期未勾选均入逾期层置底，遵守 `FB-005`）。
     - `static List<ManualEntry> filterManualEntries(List<ManualEntry> entries, {String query = '', String? selectedCourseName, AssignmentDeadlineFilter deadline = AssignmentDeadlineFilter.all, AssignmentTypeFilter type = AssignmentTypeFilter.all, required DateTime now})`：
       - 过滤 `entry.done == true`（已完成项不在首页展示）。
       - `type` 映射：`all` → 全部；`homework` / `task` → `entry.kind == 'todo'`；`exam` / `examNotice` → `entry.kind == 'exam'`（确保 `all == homework ∪ exam`）。
       - `selectedCourseName != null`：仅保留 `entry.course.trim().toLowerCase() == selectedCourseName.trim().toLowerCase()`。
       - `query.trim()` 非空：大小写无关子串匹配 `entry.title`、`entry.course` 或 `entry.location`。
       - `deadline` 过滤：
         - `all` → `true`
         - `next7Days` → `entry.at != null && entry.at!.isAfter(now) && !entry.at!.isAfter(now.add(const Duration(days: 7)))`
         - `next30Days` → `entry.at != null && entry.at!.isAfter(now) && !entry.at!.isAfter(now.add(const Duration(days: 30)))`
         - `overdue` → `bucket == AssignmentDeadlineBucket.overdue`
         - `uncertain` → `false`（手动记录时间明确或明确无截止，不归入“时间待确认”）
         - `noDeadline` → `bucket == AssignmentDeadlineBucket.confirmedNoDeadline`
         - `notExpired` → `bucket == AssignmentDeadlineBucket.notExpiredWithDeadline || bucket == AssignmentDeadlineBucket.confirmedNoDeadline`
     - `static List<HomeTimelineItem> mergeAndSort({required List<Assignment> assignments, required List<ManualEntry> manualEntries, required HomeSortOrder order, required DateTime now, List<Assignment> sourceRecords = const [], AssignmentDisplayIndex? displayIndex, bool prioritizeStartOnly = true, LocalCourseworkState coursework = const LocalCourseworkState.empty()})`：
       - 严格对齐 `AssignmentQuery.sortHome`（`assignment_query.dart:149-165, 848-927`）的 5 层模型：
         - `tier 4`：确认逾期（学习通 `bucket == overdue || elapsedNotice`；手动 `manualBucketAt == overdue`）——**在 `deadlineAsc` 与 `deadlineDesc` 两种方向下始终置底**；层内 `deadlineAsc` 按 `-time`（最近逾期在前），`deadlineDesc` 按 `+time`（最早逾期在前）。
         - `tier 0`：未逾期且有展示时间（在 `deadlineAsc && prioritizeStartOnly` 下为 `<= now + 7天`；在 `deadlineDesc` 下为全部未逾期有时间项）；层内 `deadlineAsc` 按 `+time`，`deadlineDesc` 按 `-time`。
         - `tier 1`：学习通无截止但有开始锚点的活跃课业（仅 `prioritizeStartOnly` 生效时）。
         - `tier 2`：未逾期且展示时间 `> now + 7天`（仅 `deadlineAsc && prioritizeStartOnly` 时）。
         - `tier 3`：无日期 / `confirmedNoDeadline`（含 `entry.at == null` 的手动待办）与 `unconfirmed`；层内按自然拼音/数字顺序比较 `(displayCourse, title, itemId)`。
         - `HomeSortOrder.courseName`：先按 `compareNaturalPinyin(displayCourse)`，再按时间升序（有时间在前、无时间在后），再按 `title`、`itemId`。
3. **耦合联动点**
   - `study_assistant-1.1.0/local_app/lib/src/services/home_sync_presentation.dart` 中 `HomeDueSummary.from(...)`：新增可选参数 `List<ManualEntry> manualEntries = const []`（保持默认空列表，兼容全部旧调用方）；遍历未完成且 `entry.kind == 'todo'` 且 `entry.at != null && entry.at!.isAfter(now)` 的手动待办，按 `AssignmentQuery.dayKey(entry.at!)` 计入 `dueToday` 与 `dueIn3Days`（`completedToday` 仍只统计官方今日交完，不混淆平台提交状态）。
