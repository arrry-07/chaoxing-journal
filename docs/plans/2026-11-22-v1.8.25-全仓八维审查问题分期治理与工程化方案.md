# v1.8.25+ 全仓八维审查问题、学期学年系统与工程化分期总方案

- **制定日期**：2026-11-22（2026-11-22 增补用户新需求与偏好校准）
- **审查基线**：`v1.8.24`（`1.8.24+108`，Tag `a20a072`，收口 `bf098e9`）
- **治理目标**：
  1. 将 `1.8.24+108` 八维只读审查挖出的**全部有效问题（12 项 P0、35 项有效 P1、31 项 P2、8 大类 P3 及 Top 6 超大文件耦合点）**按最优依赖顺序全部清零；
  2. 彻底解决用户新反馈的**统计页「未知 1」误导归类（已结束 AI 答题竞赛 / 账号考试纯通知）**与**统计页课程无法手动隐藏/归档**问题；
  3. 设计并落地用户迫切需要的**「当前学期 / 当前学年与课程归档系统」**，同时把**项目工程化（Wave A+ / Wave B / Wave C）**卡在最省返工的节点。
- **用户明确偏好（全局约束）**：
  - **不测试、不做 TalkBack / 系统无障碍读屏专项**（原审查 `P1-30` 及相关 TalkBack 实机项已正式取消）；
  - **平时不主动要求真机测试**，日常全部依赖本地离线回归、静态守卫与云端 CI，确实需要实机/真实样本时再提前询问维护者；
  - **工程化执行门禁**：修改脚本、Git Hooks、CI 工作流或启动 Wave B / Wave C 施工前，须先获得维护者明确确认（详见 [路线图 · 工程化门禁](../ROADMAP.md#engineering-roadmap)）。
