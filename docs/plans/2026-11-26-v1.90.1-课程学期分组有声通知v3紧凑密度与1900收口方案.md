- **代码基线锚点**：当前 `HEAD` `0341098d19035ff615668e2b7da0270f34cf92cc`（本方案落盘提交即为 `/goal` 全量 Diff 基线 `<BASE_COMMIT>`）。
- **本轮目标（`M1–M4`）**：

## 2. 关键决策与不变量

- **M1 · 学期推断优先级与时间分布投票**：
  - 优先级链重排为：`manual` > `folder` > **`activity`（课业/考试/有效通知时间分布主学期）** > `courseName` > `clazzName` > `courseStartAt` 保守兜底 > `ungrouped`。
  - **彻底弃用 `courseEndAt`**：超星课程结课时间常被设为长期开放或跨年，不得再作为 `courseTimeTerm` 依据；`courseStartAt` 仅在无上述优先信号且 `courseStartAt <= now + 180d` 时兜底使用。
  - **每条记录最多投 1 票，取代单点 `_maxUtc`**：
    - 每条非隐藏 `Assignment` 仅投 1 票（防同一作业 `publishedAt` 与 `deadlineAt` 双重计票），代表时间优先级：`deadlineAt`（可信非读取失败）或考试 `startAt`/`endAt`（可信非 `noticeOnly`）→ `availableFromAt`（`hasLiveSync`）→ `publishedAt`（`hasLiveSync`）；剔除 `> now + 365d` 的异常远期时间戳。
    - 仅当课程下无有效作业/考试投票时，才回退使用非系统广播 `CourseNotice.publishedAt`（同样每条 1 票、剔除 `> now + 365d`）。
    - **严禁将同步当天时间戳 `publishedChangeTimes`（`change.at`）混入课程基础 `term` 判定**；`publishedChangeTimes` 仅在已判定 `term < currentTerm` 且满足真实近未来/本学期官方时间信号时参与 `recallSignals`。
    - 取票数最多的学期作为课程主学期；票数并列时优先选 `<= currentTerm` 中的较近学期（若并列学期全部大于 `currentTerm`，选最早的未来学期）。
  - **保留既有硬不变量**：`FB-005` 首页逾期置底与排序契约不动；未分组课程保留精选同步资格、不污染「本学期」筛选；`matchesHomeCoursePicker` / `matchesCoursePickerScope` / `matchesAssignmentInStatsScope` 边界一致（`pastTerms` 覆盖所有 `archived` 或 `term < currentTerm` 课程）。
- **M2 · 有声 `v3` 全渠道升级、通知音量诊断与试听**：
  - 全套 4 渠道升级为全新 ID：`assignment_deadlines_v3`、`assignment_updates_v3`、`daily_summary_v3`、`personal_schedule_v3`；统一配置 `IMPORTANCE_HIGH`、`@raw/journal_chime`、`USAGE_NOTIFICATION`、`CONTENT_TYPE_SONIFICATION`、双段振动 `[0, 180, 90, 180]`、`VISIBILITY_PRIVATE`、`showBadge = true`。
  - **先建后删防丢闹钟**：严格按「先确保 `v3` 渠道创建 → 将已排程提醒重排至 `v3` → 确认成功后删除旧 `v1`/`v2` 渠道」顺序执行。`ReminderDatabase` 升至 `v10`（`onUpgrade` 将 `assignment_deadlines` 与 `assignment_deadlines_v2` 统一迁移至 `assignment_deadlines_v3`）；Dart 侧 `deadline_channel_v3_auto_migrated_v1` 必须加入 `LocalAssignmentRepository._scopedKeys` 保证账号隔离，并保留迁移后用户显式手动降级选项不被覆盖。
  - **补齐通知音量零值检测**：`MainActivity.inspectNotificationHealthDetails` 新增读取 `AudioManager.STREAM_NOTIFICATION` 当前音量、最大音量与静音态；即使 `ringerMode == normal`，当通知音量为 `0` 或处于静音时，体检页也必须明确告警提示（避免“手机没静音、但通知音量条为 0 导致只振不响”）。
  - 保留 `[23:30, 07:30)` 夜间静音、`LegacyAssignmentNotificationMigrator` 归属防线、锁屏脱敏与无原生桥接降级；`res/raw/journal_chime.wav` 须继续在 `res/raw/keep.xml` 中受保护。
- **M3 · 紧凑密度清晰生效且守住无障碍热区**：
  - 保留 `DisplayPreferences.compact` JSON 键名与序列化契约不变。
  - 开启 `compact == true` 时在非大字模式下启用单行标题并显著收紧卡片内边距与日期分组间距；所有行内按钮触控区必须保持 `>= 48×48`，`320dp@2x` 零溢出，标题/时间轨/操作按钮互不重叠（保留 `test/assignment_card_compact_test.dart` 全量断言）。
- **M4 · 纯等价收口**：
  - `AssignmentStore` 会话校验统一收口不放宽任何竞态拒绝条件；`JournalExpansionTile` 复用保留既有测试 `ValueKey`、`JournalMotion.tap` 与 reduced-motion 行为；`freeze_release.py` 改动须保持 `scripts/test_freeze_release.py` 全绿。
