## 2. 关键决策与不变量

- **M1 · 学期推断优先级与时间分布投票**：
  - 优先级链重排为：`manual` > `folder` > **`activity`（课业/考试/有效通知时间分布主学期）** > `courseName` > `clazzName` > `courseStartAt` 保守兜底 > `ungrouped`。
  - **彻底弃用 `courseEndAt`**：不再读取 `ChaoxingCourseRef.courseEndAt` 作为 `courseTimeTerm` 依据；`courseStartAt` 仅在无前述优先信号且 `courseStartAt <= now + 180d` 时兜底使用。
  - **每条记录最多投 1 票，取代单点最大时间戳**：
    - 每条非隐藏 `Assignment` 最多投 1 票（防同一作业因发布/截止时间在不同学期被重复计票），代表时间优先级：`deadlineAt`（可信非读取失败）或考试 `startAt`/`endAt`（可信非 `noticeOnly`）→ `availableFromAt`（`hasLiveSync`）→ `publishedAt`（`hasLiveSync`）；剔除 `> now + 365d` 的异常远期时间戳。
    - 仅当课程下无有效作业/考试投票时，才回退使用非系统广播 `CourseNotice.publishedAt`（同样每条 1 票、剔除 `> now + 365d`）。
    - **严禁将同步当天时间戳 `publishedChangeTimes`（`change.at`）混入课程基础 `term` 判定**；`publishedChangeTimes` 仅在已判定 `term < currentTerm` 且满足近未来/本学期官方时间信号时参与 `recallSignals`。
    - 取票数最多的学期作为主学期；平票时优先选 `<= currentTerm` 中的较近学期（若并列学期全部大于 `currentTerm`，选最早的未来学期）。
  - **既有契约不变量**：保留 `FB-005` 首页逾期置底排序契约、未分组课程精选同步资格，以及 `matchesHomeCoursePicker` / `matchesCoursePickerScope` / `matchesAssignmentInStatsScope` 边界一致性（`pastTerms` 覆盖所有 `archived` 或 `term < currentTerm` 课程）。
- **M2 · 有声 `v3` 全渠道升级、通知音量诊断与试听**：
  - 全套 4 渠道使用全新 ID：`assignment_deadlines_v3`、`assignment_updates_v3`、`daily_summary_v3`、`personal_schedule_v3`；统一配置 `IMPORTANCE_HIGH`、`@raw/journal_chime`、`USAGE_NOTIFICATION`、`CONTENT_TYPE_SONIFICATION`、双段振动 `[0, 180, 90, 180]`、`VISIBILITY_PRIVATE`、`showBadge = true`。
  - **先建后删防丢闹钟**：严格按「先确保 `v3` 渠道创建 → 将已排程提醒重排至 `v3` → 确认成功后删除旧 `v1`/`v2` 渠道」顺序执行。`ReminderDatabase` 升至 `DATABASE_VERSION = 10`（`onUpgrade` 将 `assignment_deadlines` 与 `assignment_deadlines_v2` 统一迁至 `assignment_deadlines_v3`）。Dart 侧新增 `deadline_channel_v3_auto_migrated_v1` 并加入 `LocalAssignmentRepository._scopedKeys`，迁移后仍保留用户显式手动降级选择不被二次覆盖，同时保证 `local_notification_service.dart` 的安装默认标记（`_installDeadlineChannelDefaultKey` / `_recordInstallDeadlineChannelDefault`）及健康状态接口与 `assignment_store.dart` 的渠道判断口径一致。
  - **系统通知音量零值诊断**：`MainActivity` 读取 `AudioManager.STREAM_NOTIFICATION` 当前音量、最大音量与静音态；即使 `ringerMode == normal`，当通知音量为 `0` 或被静音时，`ReminderHealth` 与体检页也必须明确告警提示。
  - 保留 `[23:30, 07:30)` 夜间静音、`LegacyAssignmentNotificationMigrator` 归属防线、锁屏脱敏、无原生桥接降级与 `res/raw/keep.xml` 对 `journal_chime` 的防混淆保护。
- **M3 · 紧凑密度清晰生效与无障碍底线**：
  - 保持 `DisplayPreferences.compact` JSON 键名与序列化契约不变。
  - `compact == true` 时在非大字模式下启用单行标题，显著收紧卡片内边距与日期分组间距；行内操作按钮保持 `>= 48×48` 触控热区，`320dp@2x` 零溢出且标题/时间/按钮互不重叠。
- **M4 · 纯等价收口与折叠状态隔离**：
  - `AssignmentStore` 会话守卫收口严格等价，不放宽任何 `_disposed` / `_generation` / `_authenticated` / `_account` 校验条件。
  - `JournalExpansionTile` 复用保留既有测试 `ValueKey`、`JournalMotion.tap` 与 reduced-motion 行为；调用方必须为每处实例提供明确唯一的 `toggleKey` 或隔离的 `PageStorageBucket` 状态保存策略，禁止不同分组或页面间通过 `PageStorage.maybeOf(context)` 串味。
  - `scripts/freeze_release.py` 改动须保持 `scripts/test_freeze_release.py` 全绿。
