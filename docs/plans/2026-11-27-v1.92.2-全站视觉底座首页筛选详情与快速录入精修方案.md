## 二、关键决策与不变量

1. **Refinement & Distillation（精修去噪而非推翻体系）**：守住宣纸浅色 `#F5F5F2`、深夜暖炭 `#191816`、手记钴蓝、霞鹜文楷标题与 Clawd 伴侣辨识度；不新增装饰性动效，所有操作反馈（加载、保存、筛选应用、外跳失败/回退）必须具备不依赖动画的清晰文字表达。
2. **`uiFamily` 显式脱离主题字体红线**：`StudyAssistantTheme` 全局 `fontFamily` 为 `'LXGW WenKai Screen'`，在 Flutter 中若样式写 `fontFamily: null` 仍会继承主题文楷；因此 `Journal.uiFamily` 必须设为非空系统无衬线族（如 `'sans-serif'`，配 `Journal.bodyFallback` 与 `FontFeature.tabularFigures()`），确保 `Journal.time`、`Journal.statHero`、`Journal.pillLabel` 真正以系统 UI 多字重等宽字形渲染。
3. **时间信任与 `FB-005` 排序铁律**：
   - 严守北京时间、作业/任务按截止、考试按开考、普通首页确认逾期在双向时间排序中始终置底（保留并扩充 `FB-005` 回归）。
   - 展示型考试范围绝不写回可信时间、日历、提醒或备份；官方可信时间自动接管手动截止；确认无截止显示「—」、未知显示「待定」。
   - 禁止使用 `(minutes / 1440).ceil()` 向上进位天数，消除「明天 + 剩2天」自相矛盾。
4. **存储兼容与测试完整性**：`ManualEntry.minutes` 输入框留空在保存时等价转为 `0`，不改序列化字段与加密备份结构；既有单测与组件测试仅随新交互更新入口/Key/文案，严禁删除或弱化 `FB-005`、账号 `accountEpoch` 守卫、草稿隔离与附件清理断言。
