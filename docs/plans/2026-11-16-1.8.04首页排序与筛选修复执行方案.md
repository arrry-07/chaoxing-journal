# 1.8.04 首页排序与筛选修复

用户报告考试时间并非最后却排在最后，“未逾期”筛选会让考试消失，类型“作业”只显示真实三份中的一份。基线 1.8.03+70、应用源码 `b58a4bd55980a5fc5dbb46d1e0803d7cb8481d69`；目标 1.8.04+71，旧 Tag/Release 保持不变。

- 将通知月日时分解析提取为只读时间证据，供卡片和查询共用。可信开考时间优先，其次使用同一课程/班级/考试身份的唯一通知区间。
- 无年份通知按当前北京时间年份投影，仅供列表排序和期限筛选；不写模型或备份，不生成星期，不参与日历、提醒和自动结束。冲突、仅结束和身份不一致仍不可形成开考投影。
- 时间近到远和远到近均按统一展示时间混排考试与作业；无时间项在两种方向中都置后。按课程仍先比较课程，再按展示时间比较同课程项目。
- 未筛选首页继续只显示当前待办。搜索、类型、课程或期限筛选生效时查询完整可见目录，允许已提交/已完成匹配项；期限“未逾期/已逾期”仍排除已完成记录。
- “未逾期”对唯一通知时间窗口使用同一投影。考试官方结束/取消或完成的排除；通知窗口未结束的考试保留；无法形成唯一开考时间的记录仍只在“全部”中查看。
- 首页卡片、搜索与筛选布局和持久化 JSON 不变；账号隔离、关注课程、隐藏、考试合并、提醒和日历规则保持原语义。

验收覆盖混排双向排序、课程排序、无年份当前年投影、闰日无效年份、当前年窗口结束、三份作业含两份已提交、筛选组合、清除筛选、窄屏大字和重启偏好。完成本地全量、CI、原签名双 ABI APK、保数据 MuMu、GitHub Release 与 Gitee 小索引门禁。
