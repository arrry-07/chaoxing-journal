# 作业数据体验与设置收口执行方案

**基线**：`codex/assignment-data-experience` / `7b6ab7a`，源码版本 `1.7.52+59`。

**目标**：统一期限与排序语义，修正登录和作业卡片排版，将“学习与同步”收为四个入口，并增加由系统邮件客户端确认发送的反馈草稿入口。

**边界**：群聊作业漏拉、截止年份补全、自定义交互音效、完整站内反馈服务及新增学习通接口本轮不执行。

## 已确认规则

- 首页期限筛选固定按“未逾期 → 全部 → 已逾期”展示。
- “未逾期”包含可信的未来截止作业和明确无截止作业；年份、提交状态或读取结果待确认的记录只在“全部”中查看。
- 课程名、作业名按中文无调拼音 A–Z、英文忽略大小写、阿拉伯数字自然排序。
- 邮件反馈固定发往 `397079535@qq.com`，只打开系统草稿，不接入 SMTP、服务端或发信凭据。

## 一、期限分类与筛选

1. 在 `Assignment` 增加 `deadlineBucketAt(DateTime now)`，统一返回：
   - 未逾期有截止；
   - 明确无截止；
   - 状态或截止待确认；
   - 已逾期；
   - 已完成。
2. 已完成优先归入完成；只有提交状态已确认、期限可信且本次读取未失败时，才可进入未逾期或已逾期。`status=overdue` 但日期为未来或缺失等证据冲突归入待确认。
3. 截止严格晚于 `now` 为未逾期；恰好到达截止时刻及之后为已逾期。
4. 首页筛选只显示三个选项。“全部”沿用首页未完成正式作业范围。
5. 兼容旧偏好：`noDeadline` 归一为 `notExpired`；`next7Days`、`next30Days`、`uncertain` 归一为 `all`，同时保留搜索、课程和排序。
6. 日历临时“无截止/截止待确认”范围继续独立，不写回首页偏好。

## 二、四种排序与统一逾期展示

1. `AssignmentQuery.sortHome(records, order, {required DateTime now})` 一次查询使用同一时间基准，不修改输入列表。
2. 截止近到远/远到近固定分组：
   `未逾期有截止 → 明确无截止 → 待确认 → 已逾期`。
   方向只改变有日期组内部顺序，不反转分组优先级。
3. 课程名/作业名固定分组：
   `可处理事项（未逾期或明确无截止）→ 待确认 → 已逾期`。
4. 锁定 `lpinyin 2.0.3`，以无声调拼音键处理常见多音字；英文、数字和未收录字符保留，连续阿拉伯数字按数值比较。
5. 每次排序预计算名称键；兜底顺序为原始主名称、另一名称、课程班级标识、作业 ID、原始输入序。
6. 默认分组保持“近期 → 较远未来 → 无截止 → 待确认 → 逾期”；小组件快照使用相同顺序。
7. 首页、卡片、日历、统计和小组件统一逾期边界；完成率公式保持。

## 三、登录与作业卡片

1. 协议区域改为“复选框 + 右侧文字列”，协议说明、协议正文和两个链接保持统一字号、行高与左边界；链接保留独立语义和至少 48dp 触点。
2. “课程与作业数据保存在本机。”使用 14.5sp、适度加重，并跟随系统文字缩放。
3. “需要确认”分组改为“状态或截止待确认”。
4. 无可信时间时移除无意义的“—”时间栏和对应间距；同步中保留真实进度。
5. 卡片分别展示“年份待确认”“尚未开放”“读取失败”“上次记录”等状态，并保留平台原始月日文本；不把年份缺失或漏拉写成已修复。

## 四、设置收纳

“学习与同步”顶层固定为四个入口：

1. **同步学习通**：进入现有同步页。
2. **个人安排**：二级页包含“个人待办与考试”“每日计划”。
3. **显示与小组件**：保留直接入口。
4. **学习记录**：二级页包含“学期归档”“本地记录”“已隐藏作业”“作业变化”。

新增 `/profile/arrangements`、`/profile/records` 路由。保留计数、隐藏恢复、返回路径、`/plan` 的“我的”页签归属及个人安排草稿离开保护。

## 五、邮件草稿入口

1. 复用问题描述、选填复现步骤以及应用/系统版本模板。
2. 主操作为“通过邮件反馈”；次操作为复制反馈内容、打开 GitHub 反馈页面。
3. `ExternalLinkService.composeFeedbackEmail(subject, body)` 继续走 `study_assistant/external_links`，返回值只表示系统是否接受打开请求。
4. Android 使用 `ACTION_SENDTO` 与 `mailto URI`，收件人固定在原生端 `397079535@qq.com`，主题含应用版本，正文使用反馈模板。
5. 打开成功后提示“已打开邮件草稿，请在邮箱中确认发送”；不得提示“反馈已发送”。
6. 没有邮件客户端或启动失败时保留全部输入，并提供复制反馈内容与复制收件地址；从邮件客户端返回后不得清空输入。

## 六、测试与验收

- **期限**：未来、过去、恰好到期、可信无截止、缺年、读取失败缓存、状态冲突、已完成；三筛选项与旧偏好迁移。
- **排序**：近远、远近、中文拼音、英文大小写、`作业2/作业10`、同音同名、重复键稳定性、输入列表不变、逾期始终置后。
- **跨页面**：首页、默认分组、日历当天列表、小组件、统计；不可信期限不进入可信截止提醒。
- **布局与导航**：320/390dp、1x/2x 字体、长协议文字、链接触点、原有功能从四个入口完整往返。
- **邮件**：空内容、中文/换行/特殊字符、有/无处理器、启动失败、返回保留输入；只验草稿打开，不发送测试邮件。
- **命令**：定向 Flutter 测试、全量 Flutter 测试、`dart analyze`、格式检查、上海/洛杉矶时区、原生 JVM/仪器测试编译、MuMu 实际界面与外跳核验。
