## 实施接口

- Assignment 新增 `int? activityType`、`AssignmentAvailability availability`，枚举 available/unknown/unavailable。`isFormal` 保持正式来源语义，`isSupportedClassroomTask` 只接受35/42和完整身份，`hasCourseTaskIdentity` 为两者并集，`isInAssignmentScope` 另排除unavailable。`courseTaskKey` 返回业务规范身份，`activityId` 与 `workId` 隔离。`reminderSourceKey` 为courseWork或classroomActivity:35/42。
- Client 保持 fetchAssignments/fetchAssignmentsForCourse 返回 List<Assignment>，补充 `List<SyncSourceResult> sourceResults`，来源 source 取 courseWork/classroomActivity:35/classroomActivity:42/groupHistory，phase 为 success/partial/failed/notEnabled，统计成功/失败课程、记录数、待确认数和受控 reasonCodes。正式源与活动源分开结算、分开熔断和回撤。
- 35 使用 getActiveInfoForMe/getTaskActiveInfo/getMyGroupInfo，42 使用 quizDetail2 与 getAnswerResult，核对当前账号和对象身份。明确个人证据才输出pending/submitted，其他unknown。截止仅使用可信平台绝对值或明确不限，0及缺失待确认。
- 旧活动按业务身份原位补全，保留旧记录ID和个人关联；冲突保留并报告。新明确个人状态可更新旧完成状态，unknown进入待确认并保留状态变更历史。返回核对入口同样合并unknown。
- journal 1→2，备份3→4兼容旧格式，恢复保留类型但状态unknown、时间不可信、签名链接排除。原生SQLite1→2持久化范围、status和baselinedSources，旧基线仅映射courseWork。首次新增来源静默建立基线，同轮新正式作业仍可提醒。
- 统一范围贯通首页、日历、统计、小组件、今日计划、本地记录与学期归档。35按元数据选择官方任务路径，42使用练习页，链接验证所有身份参数。界面仅改必要状态、分类文案与入口。
