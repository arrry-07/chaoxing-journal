## 二、关键不变量与架构约束

1. **首页排序与自然拼音逐位等价不变量（`FB-005`）**：优化 `_NaturalKey`、`_compareNatural`、`_PreparedAssignment` 与 `HomeManualTimeline.mergeAndSort` 后，所有排序模式（截止升序/降序、按课程、按标题）、全角符号与 Emoji（非 BMP 代理对）比较顺序及逾期置底结果必须与原 `.runes` 实现逐位一致。
2. **本机存储、损坏恢复与 `Isolate.run` 安全边界不变量**：
   - `LocalAssignmentRepository` 的损坏备份（`_backupDamagedValue` / `_backupDamaged`）、账号归属校验（`_checkOwner`）、`sessionEpoch` 与跨引擎写锁（`_serialized` / `runScopedWrite`）绝不放宽；
   - **所有 `Isolate.run` 入口必须提取为顶层函数或 `static` 纯函数**，仅传入纯值参数（`String` / 纯数据快照），**严禁在实例方法闭包内隐式捕获 `this`**（含 `Dio`、`SharedPreferences`、`Completer`、`MethodChannel` 等不可跨 Isolate 发送对象，否则运行期必抛 `Illegal argument in isolate message`）。
3. **统计与「本地记录」口径对齐不变量**：
   - 未知提交状态绝不伪写成「已完成」；
   - 修复无 `courseKey` 记录跨学期归属后，纯广播考试通知（`a.isExam && a.exam!.noticeOnly`）仅通过统计层过滤函数移出统计页完成率分母与「提交未知」桶，**不得从底层 `store.statsAssignments` / `statsAssignmentsForScope` 删除**，确保「我的 → 学习记录」（含按本学期/往期学期/账号级考试筛选且状态选「全部」）、「日历」「首页考试筛选」100% 完整可见，且统计页点击任一状态行下钻的记录数与统计页数字 1:1 严格一致。
4. **Clawd 屋顶舞台盒内正坐标零遮挡、可触控不变量**：
   - 严禁用负 `dy` 将小人伸出 `ClawdTitleStage` 顶边之外（会导致视口/状态栏裁剪且超出父 `SizedBox` 区域丧失 Flutter `hitTest` 点击拖拽响应）；
   - 启用屋顶轨道时，`ClawdTitleStage` 盒高显式包含顶部 `roofHeadroom`（保证小人在字顶巡逻时仍有 `dy >= 0` 且脚底 `<= glyphVisualTopY`，零压字笔画、100% 保留点击/摸头/拖拽响应），右侧 4 个图标按钮加顶部偏移与标题文字保持水平居中对齐。
5. **安装身份与分发两步保底不变量**：沿用 `com.example.studyassistant.journal` 与原 v2 签名证书（`d36a5715...`），正式包必须为 `arm64-v8a` + `x86_64` 双 ABI；Gitee 同步采用「先秒级写 GitHub 索引保底 → 再上传 APK 并经匿名完整回下载 + SHA-256 + `aapt`/`apksigner` 校验后切 Gitee 主链」，任何上传/校验失败均显式报错且不破坏已生效索引。
