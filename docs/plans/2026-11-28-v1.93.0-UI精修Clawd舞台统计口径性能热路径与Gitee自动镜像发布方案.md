## 二、关键不变量与架构约束

1. **首页排序与自然拼音等价不变量（`FB-005`）**：优化 `_NaturalKey`、`_compareNatural`、`_PreparedAssignment` 与 `HomeManualTimeline.mergeAndSort` 后，所有排序模式（截止升序/降序、按课程、按标题）与逾期置底结果必须与原实现逐位一致。
2. **本机存储与跨引擎一致性不变量**：`LocalAssignmentRepository` 的损坏备份（`_backupDamagedValue`）、账号归属校验（`_checkOwner`）、`sessionEpoch` 与跨引擎写锁（`_serialized` / `runScopedWrite`）绝不放宽；仅允许对「已校验通过且原文未变」的 Key 跳过冗余 `decode`，大快照 `Isolate.run` 编码后仍须完成往返校验与 `_writeVerified`。
3. **统计口径与时间信任隔离不变量**：未知提交状态绝不伪写成「已完成」；修复账号级考试（`courseKey == null`）跨学期归属并将纯广播 `exam.noticeOnly` 移出完成率分母与「提交未知」后，原记录仍须在「本地记录」「日历」「首页考试筛选」中完整可见。
4. **Clawd 屋顶舞台零遮挡不变量**：首页小人进入标题文字 X 区间时，脚底坐标严格约束在 `<= glyphRoofY + 1dp`（位于汉字顶边之上），绝不覆盖「课业手记」笔画与右侧操作按钮，且气泡避开 `home-sync-status`；大字模式、`<330dp` 极窄屏与减弱动态自动退回右侧稳态静驻。
5. **安装身份与分发安全不变量**：沿用 `com.example.studyassistant.journal` 与原 v2 签名证书（`d36a5715...`），正式包必须为 `arm64-v8a` + `x86_64` 双 ABI；Gitee 镜像写入前必须经匿名完整下载 + SHA-256 + `aapt`/`apksigner` 验签，失败显式报错不静默伪称双渠道完成。
