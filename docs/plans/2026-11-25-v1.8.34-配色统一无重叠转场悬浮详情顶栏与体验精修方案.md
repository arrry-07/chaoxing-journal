## 1. 基线与范围

- **目标版本**：`v1.8.34`（`dev` 日常修订号；Gate 审查 PASS 后按自测包流程升至 `1.8.34+127`，未获维护者明确指令前不动 `main` / Tag / Release / 线上 `update-*.json`）
- **工作分支与代码基线**：`dev`（前置代码基线 `8eb2753`，当前自测基线 `1.8.33+126`；本轮 Stage 1 业务变更审查锚点以本方案落盘提交起算）
- **仓库门禁**：开发、安全、禁读 `docs/archive/**`、快检与提交规范遵守 [AGENTS.md](../../AGENTS.md) 与 [VALIDATION.md](../ai-workflow/VALIDATION.md)；首页排序约束与自测包流程核对 [开发与贡献.md](../guides/开发与贡献.md)。

### 本轮目标（可判定）
1. **M1 · 逾期字色清晰化、辅助墨色微深与全仓非危险红彻底统一**：取消首页与待办页未完成逾期卡片的标题/时钟灰化（主标题与左侧时钟统一恢复主墨色 `journal.ink`，清理冗余 `overdueInk` 死 token）；将浅色 `journal.muted` 由 `#434951` 微加深至 `#363C44` 增强文楷小字清晰度；清扫全仓 4 处漏网非危险红——本地记录页「已逾期」改晴空天蓝 `overdueSkyBg/overdueSky`、作业详情逾期时钟图标改 `overdueSky`、课程学习中心「未读」角标与章节「待完成任务点」改钴蓝 `slateBg/accent`、提醒状态 `unconfirmed`（「待确认」）改 `ochre/ochreBg`（仅 `queryFailed` 及真实危险/故障留红）。
2. **M2 · 无重叠切页转场与全站 Google/Telegram 级微交互精修**：一级 4 个主 Tab 切换改为 `NoTransitionPage` 极速 0 重影瞬切（动效焦点交给底部毛玻璃弹簧胶囊）；新增 `JournalPageTransitionsBuilder` 替代 Android/桌面端半透明交叉的 `FadeForwards`，正常 push/pop 走 100% 不透明实底视差横滑（左侧柔影 + 底页微退 -22% 与轻暗幕，`Cubic(0.32, 0.72, 0, 1)` 250ms），同时在 Android 14+ 边缘返回手势进行中（`route.popGestureInProgress`）无缝透传 `PredictiveBackPageTransitionsBuilder`；统计顶部 4 档 `_StatsTermScopeBar` 底部钴蓝指示条改平滑滑动跟手滑块；为高频按钮/胶囊提供统一可复用的按压微缩反馈（`scale 0.96`，110ms `easeOut`，遵守 `isReducedMotion`）。
3. **M3 · 作业与待办详情页现代悬浮顶栏与全站二级页顶栏尺寸统一**：新增 `JournalFloatingDetailHeader` 组件并重构 `AssignmentDetailScreen` 顶部区域——移除 `ListView` 内过小且会滚走的 `TextButton.icon` 行，改为左上角固定 `42dp` 毛玻璃圆形悬浮返回按钮（`22dp` 图标、`48×48dp` 触控区，保留 `ValueKey('assignment-detail-back')`）+ 右上角等高毛玻璃「置顶/已置顶」胶囊（保留 `ValueKey('assignment-detail-pin')` 与 `'置顶'/'已置顶'` 文本）；下滑越过标题卡后顶部平滑渐显毛玻璃紧凑栏展示浓缩单行标题，左右按钮始终跟手固定；同步对齐 `ManualEntryDetailScreen` 返回尺寸与详情顶栏视觉语言。
4. **M4 · 课程「未分组」专项治理（源头补提 + 筛选去噪 + 课程管理一键批量归类）**：升级 `ChaoxingApiParser` 与 `CourseRef`（保持 `BackupSnapshot schema 9` 向后兼容可选字段），补提班级名 `clazzName`、文件夹节点 `name` 兜底及课程起止时间戳 `courseStartAt/courseEndAt`；扩展 `CourseTermCatalog` 判期链路为 `manual > folder > courseName > clazzName > activity > courseTime > ungrouped` 并补齐高校常见简写（`25-26(1)`、`25-26-1`、`25秋/春`、`2025年第一学期`、`2025-2026上/下`等，严守防误判「2025级」「202501班」红线）；首页课程筛选弹层 `HomeCourseFilterOption.subtitle` 去掉刺眼的「未分组」副标（仅干净展示教师/班级，无依据课继续温和沉底）；「我的课程」管理模式支持多选勾选 + 底部一键批量操作条（批量标为本学期 / 批量归档 / 批量屏蔽）。
5. **M5 · P2 收口：全仓 13 处 `ExpansionTile` 统一平滑折叠 + `AssignmentStore` 会话归属校验收敛**：抽离公共 `JournalExpansionTile`（`AnimatedSize` + `easeDrawer` 220ms + 箭头 `AnimatedRotation` 180° + 支持 `PageStorage` 保持展开态 + 无障碍语义与 `isReducedMotion`），替换全仓 6 个文件全部 13 处原生 `ExpansionTile`，并在 `ui_design_system_guard_test.dart` 加入 0 原生 `ExpansionTile` 静态守卫；收敛 `AssignmentStore` 中重复多处的四条件会话归属校验为统一私有 `_isSessionCurrent(...)` helper（纯结构收口，零行为变化）。

### 非目标
- **不开云端后端**：Supabase 反馈直发与端到端加密云同步继续延后，不进入本轮代码。
- **不改 Android 原生与发版元数据**：本轮纯 Flutter/Dart 改动，不修改 Kotlin/Gradle/通知渠道，不触碰 `main`、正式 Tag、GitHub Release 或线上 Gitee 清单；若执行期意外涉及 Android 文件须补跑 `python scripts/run_android_tests.py --local-fast`。
- **不破核心契约**：不修改 `FB-005` 逾期双向排序置底规则；不升级 `BackupSnapshot` 的 `schema` 版本号（保持 `schema 9` 向后兼容）；不改变真实危险/错误场景的 `journal.berry` 语义。
