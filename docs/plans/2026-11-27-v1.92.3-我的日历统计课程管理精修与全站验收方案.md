## 一、基线与范围

- **分支与基线**：`dev` 分支，顺序承接 `v1.92.2`（[v1.92.2 方案](2026-11-27-v1.92.2-全站视觉底座首页筛选详情与快速录入精修方案.md)）Stage 1 闭环后的最终 `HEAD`（前置基线 `8655c79`；派发执行时以当时 `dev` 上 `v1.92.2` 终版提交号锚定 `<BASE_COMMIT>`）。第二段自测打包时在 `pubspec.yaml` 与 `AppVersion` 同步递增至 `1.92.3+134`（或高于 MuMu 现装构建号）。
- **目标（覆盖 UI/UX 审查清单第 21–30 项 + 日历本月日期修复 + 全站合并实机总验收）**：
  1. **「我的」页重组、主题预览加高与 GitHub 入口**：顺序调整为「账号信息 → 我的课程（单行）→ 外观与交互 → 其他入口（课程通知与章节 + 个人待办与考试，保留动态摘要）→ 同步与提醒 → 记录与备份 → 关于与更新 → 退出登录」，删除中间单独占行的「设置」标题；三张主题预览卡加高至 `76–80dp` 并在常规首屏完整呈现；「GitHub 源码」改名为「GitHub 项目」，副文案改用 Star 邀请，点击整行打开仓库、右侧设显式「复制链接」按钮并在打开失败时附快捷复制，「检查更新」保持独立。
  2. **日历页发现性、空态文案与本月日期**：底部月/周切换改为 `minHeight >= 48dp` 带可见文字与折角图标的切换行（同时保留滑动手势）；单日空态改「当天暂无课业」（整月改「本月暂无已知日期的课业」，保留未同步/失败/待核对课业入口）；说明弹窗改「带圆圈的是所选日期」；修复「本月」整月议程卡片缺少日期上下文的问题。
  3. **统计页可读性与课程关注可撤销闭环**：顶部双排「全部」分别改为「全部学期」与「不限时间」；主指标显式标为「已完成 X / Y」配补充百分比；进度条将「待完成」从蓝系抽离为暖石板中性阶 + 段间缝隙 +「已逾期」45° 斜纹纹理（灰度下可清晰区分四态，保留全站逾期晴空蓝语义）；课程管理切换关注后弹出含影响范围说明与「撤销」按钮的轻量提示，并同步升级搜索框边框至全局 `inputFill` / `inputBorder`。
  4. **第二段合并自测打包、MuMu 全项验收与集成 PR**：Stage 1 收口推 `origin/dev` 后，新开干净第二段对话完成 `1.92.3+134` 原签名 `x86_64` 打包、MuMu 保数据 32 项 + 全套验证边界实机验收（`device_open` + `agent-device`，只读子代理审图）、日常集成 PR（`dev → main`）合入与归档两份方案。
- **非目标**：
  - 不推翻 `v1.92.2` 已拍板并落地的首页/筛选/详情/快速录入设计（仅在第二段实机发现问题时按规则回修）。
  - 本轮暂不减弱课程管理一列蓝色开关的视觉权重（按用户意见先实测切换与撤销体验再评估）。
  - 不修改正式版 `README.md`、`CHANGELOG.md`、`安装与使用.md`，不打 Tag、不发正式 Release。

## 二、关键决策与不变量

1. **「我的」入口无损精简**：将「课程通知与章节」「个人待办与考试」合入「其他入口」卡片并紧随「外观与交互」之后，完整保留原有未读数、待办数动态摘要与首页「更多」/日历「个人待办」快捷入口；常规首屏确保完整露出三张加高主题卡，窄屏大字沿用纵向重排。
2. **统计下钻与口径不变量**：文案区分与视觉增强不改变任何统计口径（已关注课程 + 账号级考试、隐藏不计入、未知计入总数、时间窗口排除无确定时间记录），点击状态行与课程行下钻仍完整携带 `termScope` 与 `range`。
3. **统计进度条语义色与灰度可达性**：保持全站「已完成 = 钴蓝」「已逾期 = `journal.overdueSky` 晴空蓝」，禁用非危险刺眼红；将「待完成」从浅蓝改到暖石板中性灰阶，并配合段间留白与「已逾期」斜纹保证色弱/灰度下四态互不混淆。
4. **课程关注撤销安全守卫**：撤销回调必须核对 `store.accountEpoch` 与操作前课程 key，防止切号或异步刷新后误覆盖新账号配置；MuMu 实测切换后必须还原原关注状态并保留登录与课程数据。
