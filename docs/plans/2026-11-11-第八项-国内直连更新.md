## 需求和当前代码

用户补充：少于10位用户、预算10元、没有云账号和域名、更新频繁。预算按上轮问题暂解释为每月10元；这不是开通付费服务授权。不要再询问已知用户数和是否有域名；必要时只确认实际月下载次数或一次性域名支出。

重要修正：不能假设新建 COS/OSS 桶的默认 HTTPS 域名可以分发 APK。腾讯官方规定2024-01-01后新桶默认域名不支持APK/IPA下载；阿里官方规定2023-08-15后新桶默认域名的APK/IPA匿名或签名请求被阻断。两者需要核对自定义域名、HTTPS及备案条件。因此无域名情况下不将 COS/OSS 作为可立即使用的免域名推荐，不用改后缀规避分发限制。

- [腾讯默认域名APK限制](https://cloud.tencent.com.cn/document/faq/436/102489)
- [阿里默认域名APK限制](https://help.aliyun.com/zh/oss/user-guide/48-00000200)

成本压力测试已按当前正式包57,523,043字节重算：仅按历史示例0.50元/十进制GB、10位用户每轮全部下载，月10/20/30轮约5.75/11.50/17.26GB，对应2.88/5.75/8.63元纯流量。不是新报价，未计域名、请求、存储与重试；30轮的费用余量很小，10元不保证覆盖全部成本。每次发布后按实际APK大小重算。只发布而无人下载不会产生相同下行费用。

本规模的当前推荐顺序：先用最终release包验证免费Gitee附件及清单匿名直连；不满足大小/访问/条款条件则停止该候选，不强拆文件。其次再比较有明确APK分发能力的托管服务或自有域名方案的全年总费用，用户确认一次性支出后才能开通。R2没有域名且未验证大陆网络时不作为已可用替代。暂不购买服务器、CDN套餐或大容量资源包。频繁开发包可以只由维护者测试，但不能为了省钱擅自更改用户已有手动检查补丁规则。

目标：普通中国大陆 Android 用户关闭 VPN 后，能够在应用内检查版本、下载 APK、校验并进入安装，不需要登录下载网站、验证码或第三方下载器。下载地址不能只是跳到 GitHub 的网页。

Flutter 根目录 `study_assistant-1.1.0/local_app`：

- `lib/src/services/app_update_service.dart`：AppUpdateInfo、checkConfigured、checkForManualUpdate、checkForStartup、downloadApk；默认 GitHub API，支持 UPDATE_MANIFEST_URL。已有 APK 大小、哈希和资源限制。
- `lib/src/services/app_update_controller.dart`：应用级更新任务，必须复用，不能另开一套下载管理器。
- `lib/src/services/apk_download_transport.dart`、`parallel_apk_transfer.dart`：现有下载传输。先读实现和调用方，不默认开启并发或声称已有跨进程断点续传。
- 现有 manifest 字段：versionCode、versionName、apkUrl、sha256、applicationId，以及可选 size/notes。先核对解析代码和测试再扩展。
- 服务层checkForStartup配置manifest时调用checkConfigured，但AppUpdateController.check已经通过isNewIteration过滤启动补丁候选；不能写成当前缺少启动静默保护。尚缺stable/manual双入口及其专项回归，改造必须保留现有major/minor和忽略版本规则。
- `scripts/update-manifest.ps1` 已生成含哈希和大小的单清单，应扩展复用；当前不负责上传、回下载验证或清单发布顺序。配置单清单后已直接访问清单，不先请求GitHub；待完成的是正式国内源部署与双入口，不必重写这一能力。
- 现有清单解析对applicationId/versionName主要检查非空，不代表已经匹配本应用和版本格式；后续APK安装检查仍存在。新增源须明确补上清单阶段目标匹配与有效版本检查，复用下载大小与哈希校验，不删除安装前检查。

## 候选方案与初步结论

以下来自官方资料，价格和资格在正式开通前重新确认；未实测大陆三网。

| 候选 | 免费条件或费用依据 | 适用判断 |

| Gitee Release 附件 | 普通单附件 100M、仓库总附件 1G；GVP 等另有额度 | 免费试验候选。先测最终签名 release APK 大小、匿名 HTTPS 直链是否返回文件而非登录页、重定向、限流和清单访问。不能先承诺可用。 |
| Cloudflare R2 标准存储 | 每月 10GB-month、100万 A 类/1000万 B 类操作免费，出网流量免费；超额及其他服务可收费 | 若有自有域名可作为低成本候选。r2.dev 是限流开发入口，不用于正式更新。大陆稳定性要实测，免费不等于直连可靠。域名费用另计。 |
| 腾讯云 COS 中国大陆地域 | 新用户免费额度主要抵标准存储，不抵下载流量和请求 | 国内直连付费候选；按量小规模部署优先比较，不先买服务器或大流量包。 |

| 七牛对象存储 | 官方免费额度包括标准存储和 CDN 回源等；回源额度不是用户下载免费额度 | 只有核对 HTTPS 下行、域名、CDN、备案条件与总费用后才入选，不能只看“免费10GB”。 |

2026-11-12已通过GitHub Release API核实当前v1.6.72正式APK为57,523,043字节（57.52MB），SHA-256为`9e79790b4966a13503f3e718fa7850d1245027c94e46e057ee2b35700488cb27`，低于此前官方文档的Gitee普通单附件100M限制。替换旧方案以144MB调试包判断容量的待核对项；无需拆分APK或改变双ABI策略。大小门槛通过不等于匿名直链、流量政策及国内网络已通过。下一步先验证Gitee附件实际匿名下载与清单获取，不能仅凭大小决定正式采用。

发布基线：v1.6.72已公开、latest仍v1.6.7；报告记录的是使用新版代码模拟旧版本号检查，不证明未经升级的1.6.7二进制支持发现静默补丁。保留老客户端首次国内手动下载安装的迁移计划。使用已发布资产进行镜像验证时，须保证字节与上述digest一致，不能重新打包或重签名。原GitHub资产和标签不得覆盖。见[发布验收记录](../reviews/2026-11-11-1.6.72真机验收与发布记录.md)。

目前没有足够证据宣布某个方案“永久免费且大陆稳定”。执行顺序：正式包大小检查已完成 → 验证免费候选匿名直链、清单及国内网络 → 不满足条件再按少于10人/月预算10元对比付费总成本。付费开通仍需确认，不重复询问已有用户数、预算和是否有域名。

费用估算公式：月下载流量 ≈ 正式APK字节数 × 月完整下载次数 ÷ 服务商计费GB单位；加上失败重试流量、请求、存储、域名和可选CDN费用。仅举例，100MB APK 按0.50元/十进制GB估算，100/1000/10000次下载的纯流量约5/50/500元；不是报价，未计其他项。

选择前结合上述已确认规模估算，实际下载次数仍未知时用每月10/20/30轮作压力测试。付款前提供平台、地域、当前官方单价、月费用区间、免费到期/超额规则和退出方式，用户确认后再开通。预算告警不是硬性消费封顶，必须说明服务商是否支持停用阈值。

## 实施规格

并行执行：遵守根 AGENTS.md 的协作规则，可让独立子代理分别核对免费托管限制、付费总成本与现有更新测试，主代理综合证据决定推荐。不能让多个代理同时修改 AppUpdateService/Controller；选型前只做研究和测试设计，源确认后指定一方实现，另一方只读检查补丁静默和完整性校验。没有账户或设备的实测不能交由代理“推断完成”；收费服务仍须用户确认。托管调研不阻塞前七项独立实现。

1. 清单和 APK 都使用已验证的 HTTPS 直连源；GitHub 保留为发布档案及可选备用，不得让主链路先等待 GitHub 超时才能工作。不采用未经维护者控制的公共 GitHub 代理作为正式更新源。
2. 沿用现有单版本清单格式，用两个入口区分 stable（仅大/小版本迭代）和 manual（最新可手动检查的版本，包括静默补丁）。为启动和手动分别选择清单，客户端仍验证启动仅允许 major/minor 提升；忽略版本逻辑保留。旧单 manifest 配置兼容，但也必须施加启动策略，不能让补丁自动提示。
3. 对每个清单验证版本、递增 versionCode、目标 applicationId、HTTPS、SHA-256、大小。发布文件采用版本/版本码唯一不可覆盖路径。URL 中不嵌入长期密钥，不把临时过期签名 URL 永久写进清单。
4. 上传同签名 APK 后，从公开下载地址完整下载并校验，再更新 manual 清单；只有符合迭代策略的发布才更新 stable。缓存策略：清单短缓存并可重验证，版本化APK长缓存。清单不能先于 APK 可用。
5. 默认只用一个国内主源。实现可配置的备用源时，只允许同版本同SHA-256；网络失败可切换，校验失败不能被当成功或绕过验证。切换清理不兼容临时分片，禁止拼接两个不一致对象。
6. 保留现有取消、重试、进度、首字节/总超时、磁盘和大小限制、并发开关，以及原生安装前包名/签名/SDK/ABI检查。Range 不支持时按现有协议安全回退单流；HTML错误页即使HTTP 200也不能进入安装。
7. 界面可简短显示“国内下载源”，错误区分版本检查失败、下载失败、校验失败；不要求用户开启VPN作为默认解决方式。技术配置不暴露给普通用户。
8. APK 内不放云写入密钥；发布脚本凭据使用受保护的本机/CI Secret。仅发布文件可公开读取，不擅自公开整个私有仓库或其他桶内文件。HTTPS托管、APK分发和域名条件按选定平台核实。
9. 老客户端无法凭新代码自动获得新入口。检查旧版本是否已有可远程控制清单；若没有，提供国内网页的首次手动升级包，明确迁移路径，不能宣称已修复所有已安装旧客户端。
