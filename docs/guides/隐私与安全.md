# 隐私与安全

本文按当前 Android 实现说明数据去向与使用边界。应用以本机记录为中心，登录和同步直接请求学习通接口；这仍然需要向学习通发送身份凭据和必要的请求信息。

## 哪些信息保存在哪里

| 信息 | 当前处理方式 |
| --- | --- |
| 学习通账号、密码、显示名、头像地址 | 通过 `flutter_secure_storage` 保存；Android 配置使用加密 SharedPreferences，供后续登录、同步和资料展示使用 |
| 学习通会话 Cookie | 客户端内存中维护；安全验证时会与应用内验证页面交换所需会话信息 |
| 课程、班级标识、作业标题、状态、截止时间、链接及本机隐藏记录 | 通过 SharedPreferences 写入应用本机偏好文件；不属于账号密码安全存储，不能视为全部加密 |
| 课程关注、提醒规则、同步时间 | 本机偏好设置 |
| 个人计划、清单、备注、资料链接 | 按账号保存在本机SharedPreferences；主动加密备份时包含这些数据 |
| 本地文件关联 | 仅保存用户选择的content URI和文件名，使用Android只读持久授权；不读取上传，不随备份迁移 |
| 桌面小组件和通知 | 保存/显示必要的作业快照、标题、课程及截止提示，可能出现在桌面或锁屏 |

相关实现见[账号安全存储](../../study_assistant-1.1.0/local_app/lib/src/services/secure_session_store.dart)、[学习通客户端](../../study_assistant-1.1.0/local_app/lib/src/local/chaoxing_local_client.dart)和[本机记录仓库](../../study_assistant-1.1.0/local_app/lib/src/local/local_assignment_repository.dart)。设备被解锁、Root、恶意软件或系统备份等因素会改变保护边界；安全存储并非绝对安全保证。

## 哪些操作会联网

- **登录、同步、读取资料与安全验证**：访问超星学习通服务，发送登录信息、会话 Cookie 及课程/作业请求所需参数。应用没有通过项目维护者的中转服务器处理这些请求。
- **显示头像**：头像可能从超星头像服务及其 CDN 地址联网加载，头像并非全部内置或离线资源。界面字体则随 APK 打包。
- **检查或下载更新**：冷启动会静默检查更新，用户也可主动检查；检查会请求本仓库的公开 GitHub Release API，下载时访问 GitHub 安装包托管地址，无需 GitHub 账号或令牌。显式配置 HTTPS manifest 时使用该清单覆盖默认源。更新包暂存于应用缓存，校验后调用系统安装器；没有静默安装或绕过签名的行为。
- **打开源码、发布页、反馈或其他链接**：由系统处理外部链接，浏览器会连接对应站点。点击跳转后适用该站点的数据处理方式。

联网服务可接收到 IP、请求头和请求参数等通信信息。源码中存在用于故障定位的调试输出；因此不能承诺“零日志”或“完全不上传任何数据”。公开仓库也不等于本机账号或作业应被公开。

## 保留、删除与升级

本轮整改为本机记录增加账号归属。切换账号前会归档旧账号的课程作业、隐藏、关注、提醒及同步记录，重新登录对应账号时恢复；归档同样是普通本机偏好数据，并非全部加密。退出确认会说明同时清理所有账号切换备份。Android 云备份和设备迁移明确排除安全凭据及 WebView 数据，普通 Flutter 偏好仍可能由系统备份；这不构成已经验收的完整恢复能力。

新时间以 UTC 保存、按北京时间显示。旧版本未记录时区的截止时间暂列为待确认，重新同步后再恢复可信，不猜测原设备时区。

“在本机隐藏此作业”只修改本机清单，不改学习通记录；“取消关注课程”只改变本机展示、提醒与统计范围。同步失败时应用可能继续显示上次保存的数据，应核对同步结果和学习通原页面。

应用内“退出登录”会清除保存的登录信息、本机课程作业记录及相应提醒规则，并刷新本机提醒与小组件状态。清除应用数据或卸载也可能导致本机数据丢失；这些操作不删除学习通服务器上的课程作业。

应用提供用户主动触发的口令加密备份与补缺恢复，包含个人计划、事项和学期快照；不导出登录凭据、源访问链接、服务端说明正文或文件授权。恢复不覆盖已有记录，导入作业需重新同步确认。保留记录时不要通过卸载解决覆盖安装冲突；升级必须匹配包名与签名。系统是否备份、恢复哪些内容取决于设备和系统，不能把它当作本项目已验证的数据迁移能力。

## 反馈前先脱敏

“帮助与反馈”中的复制操作会把描述、应用版本和系统版本写入剪贴板，**不会自动发送**。只有在你打开 [GitHub Issues](https://github.com/arrry-07/chaoxing-journal/issues) 并手动提交后，内容才会发布；公开 Issue 中的文字和附件可被他人查看。

提交前移除手机号、学号、姓名、密码、Cookie、令牌、班级 ID、课程/作业的个人标识与带签名完整链接。截图检查头像、账号、学校、班级和通知；日志及网页响应也需检查。优先用虚构数据、裁剪截图与脱敏错误提示复现，不上传整份本机偏好文件、会话文件或账号响应。

若怀疑密码或会话泄露，先通过学习通官方渠道修改密码并处理登录会话，再退出本应用。不要把凭据贴进公开反馈；涉及安全缺陷的公开描述也应先去除可利用的真实账号与敏感数据。

## 分发与贡献

安装包从[项目 Releases](https://github.com/arrry-07/chaoxing-journal/releases)下载，并按[安装指南](安装与使用.md)核对 `SHA256SUMS.txt`。校验能检查下载内容是否与发布值一致，不能替代对来源和签名的核对。

开发者需将签名密钥、密码、`key.properties`、本机 SDK 路径和用户数据保留在仓库之外。项目不提供默认正式签名；构建与贡献说明见[开发与贡献](开发与贡献.md)。

每日摘要默认关闭，只按本机快照安排未来7天的通知，内容含数量和快照日期；开启后也受系统通知与后台限制影响。

个人待办、手动考试及学期快照按账号保存在本机偏好文件，主动导出时包含在加密备份中；没有新增考试联网接口。个人提醒可能在锁屏显示事项标题。学期快照不包含服务端访问链接或本地文件授权，保存快照不删除活动数据。

通知默认隐藏课程、作业与个人事项详细内容，可在提醒设置主动开启；系统通知设置仍会影响锁屏显示。启动及后台同步不主动申请权限，可在提醒设置分别管理通知与精确闹钟权限。小组件仍可显示课业详情，含快照保存时间，范围在保存设置或同步时更新，不代表实时平台状态。
