# 安装与使用

学习通课业手记面向 Android，帮助查看课程作业、截止日历、提醒和桌面小组件。**首次安装和手动升级均下载 1.7.5+57。** 需要 **Android 8.0 或以上**，支持 **ARM64 / x86_64**，不支持仅有 32 位 ARM 的设备。

## 下载安装

1. [下载 chaoxing-journal-1.7.5.apk](https://github.com/arrry-07/chaoxing-journal/releases/download/v1.7.5/chaoxing-journal-1.7.5.apk)，并从[同一发布页](https://github.com/arrry-07/chaoxing-journal/releases/tag/v1.7.5)下载 SHA256SUMS.txt。已安装用户直接覆盖安装，勿先卸载；普通使用者无需安装 Flutter。
2. 核对 APK 的 SHA-256 与同一发布页 `SHA256SUMS.txt` 中对应文件的一行一致。在下载目录中可运行：

   ```powershell
   Get-FileHash -Algorithm SHA256 -LiteralPath .\chaoxing-journal-1.7.5.apk
   Get-Content -LiteralPath .\SHA256SUMS.txt
   ```

   Linux 可运行 `sha256sum -c SHA256SUMS.txt`，macOS 可运行 `shasum -a 256 -c SHA256SUMS.txt`。校验值不一致时重新下载，不要安装该文件。
3. 在手机上打开 APK，按系统提示临时允许当前浏览器或文件管理器安装应用，然后确认安装。

当前体验包的包名为 `com.example.studyassistant.journal`，沿用维护者既有体验发布证书；候选使用签名 Release 构建，不更换包名或证书。**升级请直接覆盖安装，勿先卸载。** Android 覆盖安装要求包名和签名均相同；自行编译的调试包通常使用另一把本机调试密钥，不能据此假定可覆盖发布包。安装提示签名冲突时保留旧应用，先核对包来源和发布说明。

支持在“我的 → 加密备份与恢复”导出当前账号的作业、课程、计划、个人清单备注、手动安排、学期快照与提醒设置。登录凭据、个人资料、作业访问签名、说明正文和本地文件关联不导出；手动添加的资料链接会随加密备份保存。恢复前需要输入口令、解密预览并核对账号归属，明确确认后仅补入本机缺少的记录，不覆盖已有记录；恢复后仍需同步学习通确认提交状态和截止时间。备份文件与口令应分开保管，忘记口令无法恢复。卸载或清除应用数据前先导出备份；不要把截图或系统备份视为已验证的应用数据恢复方案。

## 首次同步与日常刷新

使用自己的学习通账号和密码登录，无需先安装学习通官方 App。登录后会开始读取作业；遇到登录失效需重新登录，遇到安全验证则按应用提示完成验证后继续。

首页右上角的循环箭头是“刷新作业”，旁边的省略号进入“同步详情”。首次同步会先显示课程和作业，再逐份确认截止时间；已确认记录立即出现，尚未完成的卡片显示“正在确认截止时间”。刷新时连续点击不会重复发起。当前首页已取消下拉刷新，请使用该按钮。

刷新结束会显示更新成功、部分截止时间待确认、部分课程未更新或失败等结果。失败时保留的上次记录不能代表最新提交状态；查看“同步详情”，根据提示重试、重新登录或完成安全验证。也可从“我的 → 同步学习通”进入该页面。

## 课程、作业和日期

- **管理关注课程**：进入“我的”，点击“我的课程”卡片右上角的调节图标（管理全部课程）。开关影响首页、日历、提醒、小组件及统计；取消关注不会从学习通删课，同名课程按班级分别管理。
- **找回未显示的记录**：到“我的 → 本地记录”查看已完成、已隐藏、未关注及历史来源的记录。隐藏的作业也可在“我的 → 已隐藏作业”恢复。
- **隐藏作业**：作业详情中的“在本机隐藏此作业”只改变本机显示，不会提交作业，也不会修改学习通的提交状态。实际作答与提交仍需在学习通完成。
- **区分截止状态**：日期已确认且早于当前时间的作业才进入按日期判断的过期分组。截止时间读取失败、历史时间不可信或提交情况不明的记录会进入待确认；“待确认”不等于“无截止”或“已过期”。来源明确表示无截止时间时才按无截止处理。遇到疑问请核对学习通原页面。

首页主要展示关注课程中的未完成正式作业。学习通显示的已提交、待批阅、已批阅等状态与本机隐藏是不同信息；同步和解析可能受学校接口、登录状态和页面变化影响。

## 提醒与小组件

在“我的 → 提醒设置”可分别配置：

- **白天后台检查**：学习通作业默认开启，每 4 小时在手机当前时区的 `08:00—次日 00:00` 内检查，可选 2、4、6 小时。08:00 是目标时间，WorkManager 可能因系统调度延后；凌晨迟到任务会改到当天 08:00，不补跑一整晚的多个时点。
- **学习通通知触发核对**：默认关闭。开启后还需在系统“通知使用权”中授权；应用只处理 `com.chaoxing.mobile` 的通知信号，不保存通知正文，也不按通知文本猜测作业。未知格式会回到正常同步确认。
- **新增正式作业提醒**：默认开启。首次完整同步只建立基线，不集中提醒历史作业；之后同一次检查发现多条时合并成一条通知。隐藏、取消关注、已完成或可信截止已过的作业不再提醒。
- **截止提醒**：继续使用原提醒规则。原提醒时点落在 `00:00—08:00` 时顺延到当天 08:00，届时已截止则取消；断网时保留缓存快照，已安排的本地截止校验仍可工作。

第一次开启通知或系统要求权限时，应用会在用户主动操作后请求或打开系统设置。桌面小组件可通过系统桌面的“小组件”入口添加，显示最近一次保存的本机作业快照。

提醒依据已同步的可信截止时间安排本地通知。未知或待确认日期可用于“截止时间待确认”的新增提醒，但不会据此安排虚假的截止倒计时。系统省电、强行停止、厂商后台限制、通知权限、通知渠道及设备锁屏设置都可能影响投递，不能保证必达。

个人待办、手动考试和每日摘要沿用原规则，不套用学习通作业的白天窗口。可以关闭“白天后台检查”而不影响独立开启的通知监听或缓存截止提醒，但学习通作业不会再由定时兜底自动刷新。

## 更新与反馈

1.3.0起每次冷启动静默检查更新；新版弹窗可关闭或忽略当前版本，忽略不影响手动检查。下载默认缓冲单连接，较慢时可勾选“尝试多连接加速”，速度受网络影响。

到“我的 → 检查更新”可按当前客户端的更新规则检查正式版本。1.7.4 仍为 latest，1.7.5 是手动补丁：已安装 1.7.4 的用户可手动检查或从网页覆盖安装，不会收到启动更新提示；旧 1.6.7 只读取 latest（1.7.4），不会发现 1.7.5。检查中、已是最新、发现新版、网络失败和访问频率限制都有明确结果；失败时可重新检查或打开 GitHub 发行版。

发现新版后点击“下载并安装”，可查看下载进度，或点击“后台下载”收起弹窗，继续浏览和切换页面。底部进度条可重新打开任务；后台完成后点击“安装更新”。取消下载后可重试；校验失败不会安装，临时文件失效后可重新下载。这里的后台下载由应用进程持有，系统结束进程后不保证继续，也不承诺断点续传。

检查与下载需要网络能访问 GitHub 及其安装包托管服务。遇到连接超时可稍后重试，或用弹窗中的“查看 GitHub 发行版”通过浏览器下载；下载失败不会改动已有应用或作业记录。

应用会校验 SHA-256，并由 Android 检查包名、签名、版本、系统与架构兼容性。首次更新可能需允许本应用安装其他应用，授权后返回点“安装更新”重试；最终由系统确认安装。安装器取消后仍可再次尝试。

**旧版 1.2.7 及以前的应用内更新入口限制：** 这些版本没有应用内更新入口。若希望从旧版开始使用应用内检查更新，需先从发布页手动安装 1.2.8；这是启用应用内更新能力的桥接步骤。若直接从 Releases 手动安装当前版本，则不必先经过 1.2.8：[v1.2.7 Release](https://github.com/arrry-07/chaoxing-journal/releases/tag/v1.2.7) 说明其包名为 `com.example.studyassistant.journal` 且沿用此前体验签名，versionCode 为37；[v1.2.8 Release](https://github.com/arrry-07/chaoxing-journal/releases/tag/v1.2.8) 为同包名/同体验签名、versionCode 38。直接升级仍必须核对来源、包名、签名和递增 versionCode；签名冲突时不要卸载旧版。

问题可在“我的 → 帮助与反馈 → 意见反馈”填写、复制，再到 [GitHub Issues](https://github.com/arrry-07/chaoxing-journal/issues) 手动提交。复制按钮不会自动发送。附应用版本、Android 版本、操作步骤和实际提示；先移除手机号、密码、Cookie、班级 ID、带签名的完整链接及截图里的个人信息。详见[隐私与安全](隐私与安全.md)。


## 每日计划与个人记录

首页“今日计划”可选择日期、添加未完成作业并填写预计分钟数，之后可调整、移除或勾选个人完成。未完成项保留在原日期，不自动改成平台逾期。个人勾选不影响学习通提交结果。

作业详情的“个人清单与备注”可添加清单、备注、HTTPS资料链接及本地文件关联，更改后点击保存。文件通过Android系统选择器取得只读授权，不复制或上传；移动文件或撤销权限后需重新关联。

“我的 → 提醒体检”可查看通知权限、精确提醒权限、已安排通知数，并主动发送测试通知。每日摘要默认关闭，开启后按北京时间、以当前快照预安排未来7次每日摘要；重进应用、同步或修改设置时重排。超过7天未打开将停止，时间可能受系统调度影响，不能代替实时同步。

加密备份现包含个人计划、清单、备注和手动资料链接，兼容1.3.0生成的旧备份。恢复只补缺，保留本机已有个人条目和摘要设置；文件本身及文件授权关联不迁移。1.3.0无法读取新版备份，恢复前请升级。


## 个人待办、考试与学期归档

“我的 → 个人待办与考试”可添加、编辑、勾选完成或确认删除个人安排。待办可暂不填写时间，手动考试必须填写日期和时间，均按北京时间处理；可选择提前30分钟提醒。没有日期、已完成或提醒时点已过的事项不会安排未来通知。考试信息需自行核对教务通知，应用尚未同步考试接口。

日历显示作业与未完成手动事项的合计数量，所选日期列出对应事项；个人待办不会变成学习通作业，也不计入平台提交率。

“我的 → 学期归档”将当前账号本机全部正式作业（含本机隐藏记录）、个人笔记、计划和手动安排保存为一份命名快照。保存前建议先同步核对。快照只读，不随后续同步或勾选变化；保存和删除快照均不删除/隐藏当前记录。预计分钟仅为手动记录逐项合计，不代表实际学习时长或成绩。

最多500项个人安排、12份快照，每份最多2000条作业；整个个人手记总计4MiB。快照省略作业访问签名、说明正文和本地文件关联，手动填写的资料链接仍会保留。加密备份schema3包括个人安排和快照，兼容schema1/2；恢复按ID只补缺。旧版应用不能读取新版备份，请先升级。
