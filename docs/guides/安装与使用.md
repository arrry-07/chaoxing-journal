# 安装与使用

学习通课业手记面向 Android，帮助查看课程作业、截止日历、提醒和桌面小组件。**当前正式版本为 `1.8.11+78`。** 需要 **Android 8.0 或以上**，支持 **ARM64 / x86_64**，不支持仅有 32 位 ARM 的设备。

## 下载安装

1. [下载 chaoxing-journal-1.8.11.apk](https://github.com/arrry-07/chaoxing-journal/releases/download/v1.8.11/chaoxing-journal-1.8.11.apk)，并从[同一发布页](https://github.com/arrry-07/chaoxing-journal/releases/tag/v1.8.11)下载 SHA256SUMS.txt。已安装用户直接覆盖安装，勿先卸载；普通使用者无需安装 Flutter。
2. 核对 APK 的 SHA-256 与同一发布页 `SHA256SUMS.txt` 中对应文件的一行一致。在下载目录中可运行：

   ```powershell
   Get-FileHash -Algorithm SHA256 -LiteralPath .\chaoxing-journal-1.8.11.apk
   Get-Content -LiteralPath .\SHA256SUMS.txt
   ```

   Linux 可运行 `sha256sum -c SHA256SUMS.txt`，macOS 可运行 `shasum -a 256 -c SHA256SUMS.txt`。校验值不一致时重新下载，不要安装该文件。
3. 在手机上打开 APK，按系统提示临时允许当前浏览器或文件管理器安装应用，然后确认安装。

当前体验包的包名为 `com.example.studyassistant.journal`，沿用维护者既有体验发布证书；当前正式版使用签名 Release 构建，不更换包名或证书。**升级请直接覆盖安装，勿先卸载。** Android 覆盖安装要求包名和签名均相同；自行编译的调试包通常使用另一把本机调试密钥，不能据此假定可覆盖发布包。安装提示签名冲突时保留旧应用，先核对包来源和发布说明。

支持在“我的 → 加密备份与恢复”导出当前账号的作业、课程、计划、个人清单备注、手动安排、学期快照与提醒设置。登录凭据、个人资料、作业访问签名、说明正文和本地文件关联不导出；手动添加的资料链接会随加密备份保存。恢复前需要输入口令、解密预览并核对账号归属，明确确认后仅补入本机缺少的记录，不覆盖已有记录；1.8.0 导出 schema 5 备份，需 1.8.0 或更新客户端恢复；仍支持读取 schema 1–4 旧备份。恢复后仍需同步学习通确认提交状态和截止时间。备份文件与口令应分开保管，忘记口令无法恢复。卸载或清除应用数据前先导出备份；不要把截图或系统备份视为已验证的应用数据恢复方案。

## 首次同步与日常刷新

使用自己的学习通账号和密码登录，无需先安装学习通官方 App。登录后会开始读取作业；遇到登录失效需重新登录，遇到安全验证则按应用提示完成验证后继续。

首页右上角的循环箭头是“刷新作业”，旁边的省略号进入“同步详情”。首次同步会先显示课程和作业，再逐份确认截止时间；已确认记录立即出现，尚未完成的卡片显示“正在确认截止时间”。刷新时连续点击不会重复发起。当前首页已取消下拉刷新，请使用该按钮。

正式作业、个人/分组任务与随堂练习独立读取，不依赖收件箱是否收到通知。刷新结束会显示更新成功、部分截止时间待确认、部分课程未更新或失败等结果；在同步详情的“读取来源”查看各来源数量。独立课程群云历史与消息卡片仍未接入，可能还有遗漏。失败时保留的上次记录不能代表最新提交状态；查看“同步详情”，根据提示重试、重新登录或完成安全验证。也可从“我的 → 同步学习通”进入该页面。

## 课程、作业和日期

- **管理关注课程**：进入“我的”，点击“我的课程”卡片右上角的调节图标（管理全部课程）。开关影响首页、日历、提醒、小组件及统计；取消关注不会从学习通删课，同名课程按班级分别管理。
- **找回未显示的记录**：到“我的 → 学习记录 → 本地记录”按来源、状态、同名多班课程、关键词和排序条件检索已完成、已隐藏、未关注及历史来源的记录。点击“已隐藏作业”可直接定位到“已隐藏”视图，并在详情页查看与一键恢复。
- **隐藏作业**：作业详情中的“在本机隐藏此作业”只改变本机显示，不会提交作业，也不会修改学习通的提交状态。实际作答与提交仍需在学习通完成。
- **区分截止状态**：日期与提交状态可信、且截止时间已经到达或早于当前时间的作业才进入已逾期分组。截止时间读取失败、历史时间不可信或提交情况不明的记录会进入待确认；“待确认”不等于“无截止”或“已逾期”。来源明确表示无截止时间时才按无截止处理。遇到疑问请核对学习通原页面。

首页主要展示关注课程中的未完成课业，包括正式作业、课程任务和考试。学习通显示的已提交、待批阅、已批阅等状态与本机隐藏是不同信息；同步和解析可能受学校接口、登录状态和页面变化影响。

## 提醒与小组件

在“我的 → 提醒设置”可分别配置：

- **白天后台检查**：学习通作业默认开启，每 4 小时在手机当前时区的 `08:00—次日 00:00` 内检查，可选 2、4、6 小时。08:00 是目标时间，WorkManager 可能因系统调度延后；凌晨不执行，迟到的检查顺延到下一个可用窗口，多个错过的时点合并为一次，不补跑整晚。
- **学习通通知触发核对**：默认关闭。开启后还需在系统“通知使用权”中授权；应用只处理 `com.chaoxing.mobile` 的通知信号，不保存通知正文，也不按通知文本猜测作业。未知格式会回到正常同步确认。监听信号与联网读取的考试通知是两条不同路径：前者只提供触发信号，后者才解析考试名称、时间、时长和地点。
- **新增正式作业提醒**：默认开启。首次完整同步只建立基线，不集中提醒历史作业；之后同一次检查发现多条时合并成一条通知。隐藏、取消关注、已完成或可信截止已过的作业不再提醒。
- **截止提醒**：继续使用原提醒规则。原提醒时点落在 `00:00—08:00` 时顺延到当天 08:00，届时已截止则取消；断网时保留缓存快照，已安排的本地截止校验仍可工作。

第一次开启通知或系统要求权限时，应用会在用户主动操作后请求或打开系统设置。桌面小组件可通过系统桌面的“小组件”入口添加，采用手账暖纸风格，随有效高度在 2 / 4 / 6 行静态布局间自适应切换并展示范围待办计数、逾期／临近标记与剩余未展示提示。

提醒依据已同步的可信截止时间安排本地通知。未知或待确认日期可用于“截止时间待确认”的新增提醒，但不会据此安排虚假的截止倒计时。系统省电、强行停止、厂商后台限制、通知权限、通知渠道及设备锁屏设置都可能影响投递，不能保证必达。

个人待办、手动考试和每日摘要沿用原规则，不套用学习通作业的白天窗口。可以关闭“白天后台检查”而不影响独立开启的通知监听或缓存截止提醒，但学习通作业不会再由定时兜底自动刷新。

## 更新与反馈

1.3.0起每次冷启动静默检查更新；新版弹窗可关闭或忽略当前版本，忽略不影响手动检查。下载默认缓冲单连接，较慢时可勾选“尝试多连接加速”，速度受网络影响。

到“我的 → 检查更新”可按当前客户端的更新规则检查正式版本。1.7.55 起默认并行检查 Gitee `update-manual.json` 与 GitHub 正式 Release；两源取较高版本，同版本优先 GitHub 元数据，摘要与大小一致时优先 Gitee 下载地址并保留 GitHub 备用。Gitee 清单或网络失败时仍使用 GitHub 结果。更早客户端的行为以其发布说明为准；首次升级仍可能需要手动检查或网页覆盖安装。

发现新版后点击“下载并安装”，可查看下载进度，或点击“后台下载”收起弹窗，继续浏览和切换页面。底部进度条可重新打开任务；后台完成后点击“安装更新”。取消下载后可重试；校验失败不会安装，临时文件失效后可重新下载。这里的后台下载由应用进程持有，系统结束进程后不保证继续，也不承诺断点续传。

检查与下载需要网络能访问 GitHub 及其安装包托管服务。遇到连接超时可稍后重试，或用弹窗中的“查看 GitHub 发行版”通过浏览器下载；下载失败不会改动已有应用或作业记录。

应用会校验 SHA-256，并由 Android 检查包名、签名、版本、系统与架构兼容性。首次更新可能需允许本应用安装其他应用，授权后返回点“安装更新”重试；最终由系统确认安装。安装器取消后仍可再次尝试。

**旧版 1.2.7 及以前的应用内更新入口限制：** 这些版本没有应用内更新入口。若希望从旧版开始使用应用内检查更新，需先从发布页手动安装 1.2.8；这是启用应用内更新能力的桥接步骤。若直接从 Releases 手动安装当前版本，则不必先经过 1.2.8：[v1.2.7 Release](https://github.com/arrry-07/chaoxing-journal/releases/tag/v1.2.7) 说明其包名为 `com.example.studyassistant.journal` 且沿用此前体验签名，versionCode 为37；[v1.2.8 Release](https://github.com/arrry-07/chaoxing-journal/releases/tag/v1.2.8) 为同包名/同体验签名、versionCode 38。直接升级仍必须核对来源、包名、签名和递增 versionCode；签名冲突时不要卸载旧版。

问题可在“我的 → 帮助与反馈 → 意见反馈”填写，然后选择“通过邮件反馈”、复制内容或打开 [GitHub Issues](https://github.com/arrry-07/chaoxing-journal/issues)。邮件按钮只打开系统邮件客户端的草稿，固定收件人为 `397079535@qq.com`，不会自动发送；没有可用邮件客户端时可复制反馈和收件地址。附应用版本、Android 版本、操作步骤和实际提示；先移除手机号、密码、Cookie、班级 ID、带签名的完整链接及截图里的个人信息。详见[隐私与安全](隐私与安全.md)。


## 每日计划与个人记录

首页“今日计划”可选择日期、添加未完成作业并填写预计分钟数，之后可调整、移除或勾选个人完成。未完成项保留在原日期，不自动改成平台逾期。个人勾选不影响学习通提交结果。

作业详情的“个人清单与备注”可添加清单、备注、HTTPS资料链接及本地文件关联，更改后点击保存。文件通过Android系统选择器取得只读授权，不复制或上传；移动文件或撤销权限后需重新关联。

“我的 → 提醒体检”可查看通知权限、精确提醒权限、已安排通知数，并主动发送测试通知。每日摘要默认关闭，开启后按北京时间、以当前快照预安排未来7次每日摘要；重进应用、同步或修改设置时重排。超过7天未打开将停止，时间可能受系统调度影响，不能代替实时同步。

加密备份现包含个人计划、清单、备注和手动资料链接，当前为 schema 5，兼容读取 schema 1–4（含 1.3.0 生成的旧备份）。恢复只补缺，保留本机已有个人条目和摘要设置；文件本身及文件授权关联不迁移。旧版应用不能读取新版备份，恢复前请升级。


## 个人待办、考试与学期归档

“我的 → 个人安排 → 个人待办与考试”可添加、编辑、勾选完成或确认删除个人安排。待办可暂不填写时间，手动考试必须填写日期和时间，均按北京时间处理；可选择提前30分钟提醒。没有日期、已完成或提醒时点已过的事项不会安排未来通知。课程考试和账号考试自 1.8.0 起接入；教务考试仍需自行核对教务通知，应用不会猜测或代登录教务系统。

日历显示作业与未完成手动事项的合计数量，所选日期列出对应事项；个人待办不会变成学习通作业，也不计入平台提交率。

“我的 → 学习记录 → 学期归档”将当前账号本机全部正式作业（含本机隐藏记录）、个人笔记、计划和手动安排保存为一份命名快照。保存前建议先同步核对。快照只读，不随后续同步或勾选变化；保存和删除快照均不删除/隐藏当前记录。预计分钟仅为手动记录逐项合计，不代表实际学习时长或成绩。

最多500项个人安排、12份快照，每份最多2000条作业；整个个人手记总计4MiB。快照省略作业访问签名、说明正文和本地文件关联，手动填写的资料链接仍会保留。当前加密备份为 schema 5，包含个人安排、快照、考试来源与提醒设置，兼容读取 schema 1–4；恢复按 ID 只补缺。旧版应用不能读取新版备份，请先升级。


## 本地记录、统计下钻与手账小组件（1.8.11）

1.8.11 重构本机“本地记录”查询中心（`/records`），保留“作业与任务 / 历史与其他来源 / 已隐藏”三源隔离，增加状态芯片筛选、同名多班 `courseKey` 课程筛选、大小写无关搜索与多维排序；原“已隐藏作业”弹窗入口统一跳往 `/records?status=hidden`，详情页支持查看隐藏项及合并来源并一键恢复。

“课业统计”新增“全部（默认）/ 未来 7 天 / 未来 30 天”时间范围（采用夏令时安全的北京时间日历天边界，并在口径区说明排除的无确定时间课业数量）；点击饼图图例或各课程／账号考试卡片可下钻进入 `/records` 对应明细，保持底栏停留在“统计”且不改变首页保存的筛选。响应式多尺寸手账风桌面小组件随有效高度切换 2 / 4 / 6 行布局，无缝兼容 1.8.10 旧快照并在无界面后台检查后最佳努力刷新；提醒体检、我的课程、作业变化、显示与小组件、每日计划选择面板等 7 处授权二级页及弹窗统一对齐手账卡片风格（首页、日历与全局色板字体保持不变）。

## 考试与考试通知（1.8.10）

底栏“首页”列出当前待办，类型为全部、作业、考试；“作业”合并正式作业与课程任务（个人/分组任务、随堂练习、AI 实践）。考试沿用作业的日期标题和左侧开考时刻，右侧显示名称、课程、状态及已知时长/地点；完整起止时间在详情查看。通知未注明年份时只显示月日，不推算年份或星期。可信结束时间已到或官方明确结束/取消的考试退出当前待办，历史仍可在过去日期及本地记录查看，不据此推断个人已交卷。日历按可信开考日，提醒按可信开考时间。

“考试时间未知”专用分组和日历入口已取消，考试直接进入统一课业列表；没有开考时刻时不显示横杠或伪造时间。明确课程/班级/考试身份关联的考试和通知合并展示，原始来源记录保留；同名不等于同一考试。搜索与筛选只保留常用分类，排序为时间近到远、时间远到近、按课程，旧偏好自动兼容并跨重启保留。普通底部提示5秒、带操作12秒自动消失，无障碍模式延长；同步结果仍可从同步详情查看。

1.8.07 起，首页普通列表只展示未完成课业：已提交作业、已结束／已取消／可信结束已过的考试和历史课堂练习不在首页，可在“我的 → 学习记录 → 本地记录”和统计页查看；相同搜索、课程、期限条件下“全部”等于“作业”与“考试”结果的并集。考试和作业按统一展示时间参与“时间近到远”和“时间远到近”混排：非确认逾期且有可用时间的记录按真实时间排序（作业按截止、考试按开考），无截止、时间不可信或冲突的记录按课程与名称稳定居中，确认已逾期始终最后且层内方向正确。跨天考试的日期标题写起止范围（结束段仅跨年加年），无开考时间但有可用范围／结束的考试在卡片内写范围行；无日期记录保留左栏占位（确认无截止为“—”，其余为“待定”）并归入“无日期与待确认”分组。“未逾期”只保留确认未逾期的待办，考试需要未来开考或可用结束时间仍在未来，开考已过且结束无法判断的考试留在“全部”。类型“作业”包含正式作业及 35/42/77 课堂活动；未注明年份的通知投影只用于本次排序、期限筛选和范围显示，不写回可信日程，也不改变日历、提醒或自动结束依据。

1.8.10 新增“提醒记录与原因”：提醒体检、作业详情、已保存个人日程和每日摘要可查看最近安排、延后、提交、撤销、受阻记录及当前原因；仅本机保存最近 30 天、每账号最多 500 条，退出登录时清理。通知队列升级为账号/会话作用域，跨午夜、进程消失、部分消费和旧回调由持久尝试状态收尾；后台通知同步在读取课业前必须取得原生授权。六项可用性修复包括首页筛选/排序读屏、预览状态对比度、退出清理与备份入口、统计口径文案、日历刷新反馈和提醒保存说明。

1.8.08 将同一场考试的正式记录和关联通知合并为一项实际课业：我的页“学习记录”入口、本地“作业与任务”和“已隐藏”按分组展示、计数，统计分母不再重复；原始来源记录仍全部保留，详情页可展开查看来源类型、状态和读取时间。只有已验证的课程、班级和考试身份才合并，缺少关联身份的通知、不同活动 ID 的同名练习和不同班级考试保持独立。同一考试可整组隐藏或恢复；同组任一来源已有隐藏标记时整组保持隐藏，之后新发现的关联通知也不会重新出现在首页。

本版同时修复通知监听、个人日程、桌面组件和更新下载的可靠性：同一通知信号在失败、超时或进程中断后不会自行反复检查；个人日程会先撤销已删除、已完成、关闭提醒或提醒时间已失效的通知，再尝试新批次；桌面组件对考试显示“距开考/已开考”，对作业继续显示截止倒计时；多连接下载在读取正文前统一校验跳转安全，并只在允许的 HTTP 状态下切换完整备用源。首页视觉、逾期置底和备份格式不变。

1.8.05 同时修复手机端统计页在账号级考试没有课程键时的空白页；账号考试单独归入“账号考试”行。可信截止已过且提交状态仍未知的课程任务不再混入日历“待核对课业”和首页当前待办，原始记录仍在“我的 → 学习记录 → 本地记录”查看；正式作业状态未知时仍保留。已提交作业的截止时间会继续按同一作业详情核对，取不到新值时保留上次可信截止，卡片沿用普通作业排版。同步问题按阶段、类型和文案聚合，展开可查看受影响课程、数量和下一步处理，原始条目仍保留。

课程考试与账号考试安排分别读取；考试通知读取正文及已验证考试卡片中的真实名称、时间、时长和地点；只有课程、班级和考试身份对应才关联当前安排，名称相同不能相互补全。缺年份需要同一考试完整、匹配且唯一的时间证据，不把通知发送时间或处理时间当开考时间。原文未给实体考场时省略地点行，并保留官方入口。只讨论考试纪律等普通通知不会被列为考试安排。通知信息不足时不发定时提醒。官方入口只打开考试列表或收件箱，助手不会代为开考、读取试题或提交。来源读取失败会在同步详情保留，已有作业与任务不因此删除。

当前真实账号验证包含已完成课程考试和考试通知候选；账号安排表真实样本为空，其他个人状态、改期、取消及分页使用合成回归覆盖，未知结构会报告失败。独立群云历史仍未启用，不能将课程读取成功等同全部课业完整。


考试已完成后，关联通知也按已确认的个人完成状态展示；首页显示未完成课业，已读取的信息可在“我的 → 学习记录 → 本地记录”查看。考试改期优先采用当前官方列表；通知中的旧地点会标注需要重新核对，不作为新考场保证。通知详情仅保存整理后的原文文字，入考链接访问参数不保存；入口打开官方列表或收件箱。
