# 第二阶段：今日计划、个人记录与提醒体检

用户已批准按路线图执行。沿用现有Flutter界面、Store串行队列、账号归档及Android系统文件选择器，不重新设计视觉风格。

## 本轮交付
- 今日计划：手动选择现有作业、选择日期、填写1–1440分钟预计耗时，调整/移除和个人完成勾选；首页显示今日概览，个人完成不改变平台状态。
- 个人记录：作业备注（最多10000字符）、最多50条清单（每项最多200字符）、最多20个HTTPS资料链接、最多10个content URI本地文件关联；通过系统选择器获取只读持久授权，不申请广泛存储权限；失效文件可重新关联，不自动上传。
- 提醒体检：只读通知权限/精确提醒状态、已安排通知数和上次同步；手动测试通知不声称系统投递成功。可选每日摘要默认关闭，按北京时间设置时分，仅预安排未来7天基于当前快照的摘要，重进应用/同步时更新；内容注明数据日期。相同ID重排而非重复新增，退出/切号清理。
- 个人数据按账号保存并加入加密备份schema2；兼容schema1，恢复仅补缺个人条目/日期计划，保留现有设置；本地文件不随备份迁移。

重复操作、异步退出/切号、坏schema、错误日期、重复计划/清单、缺失文件、错链接、状态独立、备份新旧版本、摘要ID重复与关闭清理。对真实账号只做可撤销的个人记录与设置测试并恢复；不答题、不提交、不退出真实账号。
