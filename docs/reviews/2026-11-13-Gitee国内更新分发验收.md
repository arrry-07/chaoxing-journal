# Gitee 国内更新分发验收

日期：2026-11-13（Asia/Shanghai）

状态：`1.7.52+59` 候选已完成自动化、签名构建和 MuMu 覆盖验收；Gitee Release、公开清单和匿名完整下载尚待正式发布后执行。

## 范围

- Gitee 作为客户端默认更新清单和 APK 主源，GitHub 保留清单级与 APK 级备用路径。
- GitHub Actions 每日检查一次 GitHub latest，在云端完成下载、校验、Gitee 上传、清单更新和匿名复核。
- Gitee 最多保留 3 个 APK Release，stable/manual 引用始终受保护。

## 已实现

- 新客户端默认清单：
  - `https://raw.giteeusercontent.com/arrry-07/chaoxing-journal-updates/raw/master/update-stable.json`
  - `https://raw.giteeusercontent.com/arrry-07/chaoxing-journal-updates/raw/master/update-manual.json`
- Gitee 清单失败时回退 GitHub 正式 Release；有效清单、已是最新和用户取消均不触发额外 GitHub 请求。
- APK 主源瞬时失败时使用清单中的 GitHub `backupApkUrl`；摘要不一致时不回退，直接失败。
- `scripts/gitee_release_sync.py` 使用 Python 标准库调用 Gitee API，并用临时 `GIT_ASKPASS` 推送清单；Token 不进入 URL、命令行、清单或日志。
- 同步前校验 GitHub Release 状态、APK/ZIP CRC、大小、SHA-256、包名、versionCode、versionName 和固定签名证书。
- Gitee APK 匿名完整回下载通过后才提交清单。
- `.github/workflows/gitee-release-sync.yml` 只含每日 schedule 和 workflow_dispatch；不同步每个 Release。
