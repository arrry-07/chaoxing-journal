## 本轮代码改动

### 已复现缺陷：已退回且有评价的 V3 作业被降级为未知

`chaoxing_local_client.dart` 原先在 V3 正式作业列表中按以下顺序映射：

```dart
final state = evaluation != 0
    ? (status == 4 ? 'completed' : 'unknown')
    : switch (status) { ... 5 => 'returned' ... };
```

当 `stuStatus=5`（已退回）且 `evaluation != 0` 时，状态被写成 `unknown`。`LocalAssignmentRepository.merge` 对“此前已完成、当前不是 `returned`”的记录保留旧的完成状态（`:1207` 附近），因此学生看不到需要重做的作业。

### 先失败后修复

- 新增回归：`test/fanyav3_work_api_test.dart` 的 `evaluated returned work stays returned instead of becoming unknown`。
- 首跑结果：`Expected: 'returned' / Actual: 'unknown'`，确认缺陷可稳定复现。
- 修复：显式 `status == 5` 优先返回 `returned`；`evaluation` 只影响无法由 `status` 明确判断的分支。改动仅位于 `lib/src/local/chaoxing_local_client.dart:1690` 附近。
- 修复后同一回归通过；未改变分页、截止、会话代次、仓库合并或提醒事件字段。

## 仍未覆盖

1. V3 `stuStatus` 的 `1`、`2` 以及 `5` 的非评价组合仍只有代码映射，没有独立断言或真实响应样本；本轮只修复了可稳定构造的 `5 + evaluation`。
2. 课堂活动详情若返回缺年截止并同时提供可信开始时间，当前没有同类“开始锚点补年”实现或真实样本；不据此猜测。
3. 真实账号的“已退回/改期/取消”样本仍以合成夹具为主；`evaluation` 的真实取值分布未采集。
4. 考试“已结束且个人已提交”的真实样本仍缺；现有断言只证明“结束不会自动等于提交”。

## 结论与后续

- 本轮只发现并修复一处 P1：已退回且有评价的正式作业不再被误判为未知并保留旧的已完成状态。
- 其余四组场景（时间、状态、失败、下游）现有断言与实现一致；没有足够证据支持额外重构。
- 任务 6 的“随缺陷降低耦合”本轮不触发：改动是一处状态优先级修正，没有新增重复规则或难以测试的行为；核心类入口、请求预算、取消、会话代次、持久化和提醒副作用均沿用现有测试。
- 若后续获得真实 `stuStatus`/`evaluation` 样本，应优先补录一条脱敏夹具，再决定是否需要调整 `1/2/5` 的状态映射。
