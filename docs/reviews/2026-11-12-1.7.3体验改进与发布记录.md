# 1.7.3 体验改进与发布记录

日期：2026-11-12（Asia/Shanghai）

状态：1.7.3+55 曾正式公开；维护者随后要求撤回自定义应用图标，现已改为预发布归档，由 1.7.4+56 取代。

## 范围

本轮按两份执行方案完成七项体验改进与第八项更新入口代码能力：

1. 首页排序、持久化与统一列表。
2. 首次同步列表与截止详情的渐进显示。
3. Android 通知、通知渠道、通知使用权、精确闹钟、电池优化和应用详情的结构化直达与回退。
4. 课程书本图标与开放书页勾选应用图标。
5. “安排学习时间”的说明、三区块操作和保存反馈。
6. 登录协议紧凑布局与本机存储说明。
7. 学习通作业网页入口说明和既有链接边界。
8. stable/manual 双清单、国内主源配置能力、严格清单校验和同摘要备用源。
