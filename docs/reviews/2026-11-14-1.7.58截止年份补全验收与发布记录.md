# 1.7.58 截止年份补全验收与发布记录

更新时间：2026-11-14（Asia/Shanghai）

## 目标与结论

用户确认“我的课程”有多门，但首页只显示一条“年份待确认”作业。调查发现本次样本里 7 门课程均已关注、无首页筛选或隐藏记录，本机共 3 条正式作业：2 条已提交、1 条待交；首页按既有规则只显示未完成作业。正式作业接口只读核对也返回同样的 3 条记录。这不证明群聊、消息或其他来源没有作业，不能把空课直接认定为漏拉。

已定位并修复的具体缺陷：HTML 签名作业列表本身没有绝对开始时间；详情只显示“09-19 11:24 至 09-23 23:55”。同一作业正式 API 提供了北京时间 2026-09-19 11:24:47 的绝对开始时间，与页面开始时间匹配到分钟，但 1.7.57 的 HTML 分支没有把这份证据传给日期解析，导致一直标记“年份待确认”。1.7.58 只在缺年份时补查同一课程的正式接口，经课程、班级、作业身份和分页完整性校验后，用既有严格分钟匹配规则补全年份；证据不足仍保留待确认。补查不替换原 HTML 作业、标题、状态或截止值，没有改 UI、课程关注范围、登录、更新渠道或提醒，也未新增群聊/消息数据源。
