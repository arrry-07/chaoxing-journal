## 结论

代码、自动化检查和 Debug 构建已完成。学习通作业的新增/截止通知现由 Dart 规则生成计划，应用私有 SQLite 保存账号代次、基线、稳定事件和最小快照，Android AlarmManager 到时复核后投递；白天兜底检查使用唯一一次性 WorkManager 链和无界面 Flutter 入口。个人待办、手动考试与每日摘要继续使用原规则。

本轮不宣布真实账号后台同步、真实学习通通知格式、Doze/整机重启、实体手机或 TalkBack 已验证。没有执行提交、推送、Tag、Release 或 APK 上传。

## 实施结果

- 新增 `DaytimeCheckPolicy`：`08:00—次日00:00`、2/4/6 小时、跨日、延迟执行不补跑、时钟回拨处理。
- 旧`auto_sync_interval_minutes`迁移：`0`保持关闭；`120/240/360`保留；其他正值迁移为`240`；新账号默认开启`240`。
- 首次完整同步只建立基线；部分成功不建基线；基线建立后的可靠新增可提醒；已知作业重新出现不重复提醒。
- 新增作业按正式作业、服务端未完成、未隐藏、课程仍关注、截止未过过滤；同一次检查多条合并。
- 截止事件使用稳定标识与通知 ID；多规则同刻合并；凌晨时点顺延到同日 08:00，届时已截止则取消。
- SQLite 与 SharedPreferences 之间使用待更新标记和 mutation version；版本变化时拒绝旧快照计划。
- 前台、Worker 与原生接收器共享账号会话代次、同步租约和写租约；旧账号、退出或 Worker 停止后的结果不能提交。
- 旧插件`a:`作业提醒执行类别限定迁移后再启用原生投递；摘要和个人日程事务保留。
- 新增默认关闭的`NotificationListenerService`，只接受`com.chaoxing.mobile`，过滤摘要、聊天/邮件/通话类别；通知正文不落盘。
- 提醒设置加入后台检查、2/4/6 小时、通知监听和新增提醒；同步页删除旧15/30/60/自定义输入。
- 使用说明、隐私说明、开发指南、ROADMAP 和 CHANGELOG 已同步，长期约定已记录。
