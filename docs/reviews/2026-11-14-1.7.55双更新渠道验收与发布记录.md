## 实现结果

- 默认官方源并行检查 Gitee `update-manual.json` 与 GitHub 正式 Release 列表。Gitee 返回“已是最新”后仍继续比较 GitHub。
- 两源按显示版本选择候选；同版本使用 GitHub 元数据，大小与 SHA-256 一致时使用 Gitee 主地址、GitHub 备用地址。
- 同版本摘要或大小冲突时丢弃 Gitee 地址；同版本 `versionCode` 冲突时采用 GitHub 身份。
- Gitee `404/410/408/429/5xx` 可使用已验证备用 APK；摘要、大小、重定向安全或取消错误仍立即停止。
- 忽略版本改用稳定显示版本键，并兼容旧 `versionName+versionCode` 键。
- Gitee 新增 `index` 模式。GitHub `release: published` 自动更新小索引，不下载/上传 APK、不清附件；普通补丁不推进 stable。
- 未镜像版本的 `apkUrl` 为 GitHub、省略 `backupApkUrl`；批量同步完整校验后才切换为 Gitee 主地址并保留 GitHub 备用。
- 手动 `latest` 与无 tag `index` 枚举最高公开正式 Release，不依赖 `/releases/latest`。
