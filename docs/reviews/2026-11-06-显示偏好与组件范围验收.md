# 1.6.0 显示偏好与组件范围验收

## 行为
- 我的 → 显示与小组件：舒适/紧凑、日期/倒计时、本机持久保存。默认舒适与日期；紧凑仅收缩垂直间距，保留48像素操作目标和完整文字。
- 首页课程筛选按courseId/clazzId区分同名班级，只筛当前页面，不改变关注、同步、统计、日历、提醒；账号代次改变时重置。无剩余作业的筛选自动返回全部。
- 日期沿用北京时间分组；倒计时向上取整，每分钟刷新。未可信、无截止、读取失败不伪造倒计时。
- 小组件范围独立于首页筛选：全部未完成/今天剩余/未来7天（含今天），仅已关注正式作业。有限日期范围排除不可信、读取失败、已过期及无日期项。全部保留原优先顺序。
- 沿用六条快照候选，Android当前组件展示前两条。范围在保存设置与同步时更新，后台跨日不承诺即时重新筛选。通知安排不受显示设置影响；无登录状态不发布私密快照。
