- Windows 上 Kotlin daemon 可能报“Could not close incremental caches”：`gradlew --stop`、确认 java 进程退出、清理导出目录 build/ 后重建；不改构建参数。

- adb 设备路径：`export MSYS_NO_PATHCONV=1`，二进制用 `exec-out`；Flutter 语义在 uiautomator 的 content-desc 而非 text。
