## 实际截图与设备验证

`journal-home.png`、`journal-profile.png` 是 Android 11 / API 30 Google 模拟器上的实际运行截图，432×850，全部是明确标识的示例数据，不是真实学校账号。实际查看首页及我的页；完整设置修改流程由 Flutter Widget 测试验证。

相对上一《课业手记》体验版可覆盖安装；与上游原版并行。旧体验包 versionCode=29，新版=30，包名均为 com.example.studyassistant.journal。新旧签名 SHA-256 均为 d36a571510e046dd196d7384f849f82b4fcff05ce3affb334765d5c752265d8a。

模拟器执行了旧包安装、旧版双账号/作业数据夹具写入、新包覆盖，最后断言 PASS_both_ACCOUNT_RECORDS_REMINDERS。旧包仅 ARM64 引擎而携带 x86 JNI，不能直接作为 x86运行基准；本轮新版补全 x86_64 引擎，模拟器安装显式选择 x86_64 后成功运行。此处验证的是模拟器数据迁移，不等于已在 ARM 手机验证。单学习通/仅退休平台组合由自动测试验证，未完成三组合的全部设备路径。

## 同步能力与手机确认步骤

1. 真实账号登录，核对每门课与班级的待交清单；交一份作业后回到手记手动刷新，确认待交消失、后续提醒撤销、小组件更新。接口变化、学校认证和风控仍需真实账号确认。
2. 前台返回按自动同步间隔检查；手动刷新立即查询。后台只依赖应用进程定时器，不保证被系统冻结/结束后继续联网，无推送实时同步承诺。
3. 设置一份即将截止的作业，授权通知和精确闹钟，锁屏观察时间与内容；再测试省电、重启、自启动限制。此轮未验证真机锁屏投递。
4. 在手机启动器添加桌面小组件，检查刷新与点击详情。快照内容、取消和日期处理已自动测试，真实启动器交互未验证。
5. 手机直接覆盖安装，检查账号、待交记录和提醒规则；不要先卸载。签名密钥不上传 GitHub。
